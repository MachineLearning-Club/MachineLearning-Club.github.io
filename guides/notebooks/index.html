How to use a Python notebook

A short, accountless start before Module II.

1. What is a .ipynb file?

It is a notebook containing text, executable code cells and saved outputs. Each cell is a small experiment, not a separate program you must install.

temperature = 18
print(temperature + 2)

Predict the result (20), then run the cell.

2. Open an account-free editor

  1. Open JupyterLite in a recent browser.
  2. Wait for the notebook environment to load. No account is required.
  3. Download the starter .ipynb from your week’s Laboratory page.
  4. Upload or drag the notebook into the JupyterLite file browser, then open it.

JupyterLite stores files in this browser; a different device will not automatically have them.

3. Run and change cells

  1. Click the first code cell and press Shift + Enter.
  2. Read its output before editing anything.
  3. Change one number, run the cell again and compare.
  4. If a cell uses a variable from an earlier cell, run the earlier cell first.
Why does it say NameError?

The variable may not yet exist in this running kernel. Restart and run the cells from the top in order.

4. Save and submit

  1. Use JupyterLite’s download option to save the changed notebook to your computer.
  2. Check that the file still ends with .ipynb.
  3. Use the submission area on the Laboratory page to prepare a named file.
  4. Upload it only to the teacher-approved collection location once announced.

Optional: Google Colab requires a Google account to execute; it is not the club default.
