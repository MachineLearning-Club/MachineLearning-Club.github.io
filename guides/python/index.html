12Divisibility and prime numbersA prime number is greater than one and has no positive divisors other than 1 and itself. Testing divisors up to the square root is sufficient.Core algorithm

Core idea

A prime number is greater than one and has no positive divisors other than 1 and itself. Testing divisors up to the square root is sufficient.

  1. Return False for n <= 1.
  2. Try divisors while d*d <= n.
  3. Stop as soon as a divisor is found.

19Sorting: selection sort and bubble sortElementary sorting methods help explain comparisons, exchanges and loop invariants, even though built-in sorted(...) is normally preferable.Optional

Core idea

Elementary sorting methods help explain comparisons, exchanges and loop invariants, even though built-in sorted(...) is normally preferable.

  1. Selection sort puts the smallest remaining value into its next final position.
  2. Bubble sort repeatedly swaps neighbouring values in the wrong order.
  3. Both have quadratic worst-case time for lists of length n.
