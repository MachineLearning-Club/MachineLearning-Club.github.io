Syllabus alignment

This is a club-level synthesis, not a claim that every algorithm below is compulsory in every cited national syllabus. Romania’s optional secondary-school Machine Learning curriculum provides the main local technical reference; international frameworks supply ethics, AI engineering and competition extension.

Stage I — ML foundations

Introduce algorithms using small paper-solvable examples, then investigate the same mechanisms in interactive applications and Python.

Core references: Romania: Introduction to Machine Learning, OME 4049/2022 · pyml.ro: Python & Machine Learning for high-school students · Experience AI: Foundations of AI · CBSE Class XI AI Student Handbook · IOAI 2026 Syllabus

  1. Week 1: What Is AI? Rules and Learning — AI as a field; Learning from examples; Image classification and reliability
  2. Week 2: Mathematics for Machine Learning — Data representation; Descriptive statistics; Probabilities and information
  3. Week 3: Decision Trees: ID3 — Readable models; How ID3 chooses a split; How trees generalise
  4. Week 4: Numeric Splits and Evaluation — Continuous decision rules; Model validation; Error metrics
  5. Week 5: K-Nearest Neighbours — Geometry and similarity; K-nearest neighbour classifier; Practical model behaviour
  6. Week 6: K-Means Clustering — Unsupervised learning; K-Means: assign and update; Where clustering fails
  7. Week 7: Linear Regression — Predicting continuous outcomes; Learning a linear relationship; Checking predictions
  8. Week 8: Computer Vision — Pixels are arrays; Kernels and local computation; Feature extraction to classification
  9. Week 9: Perceptrons and Neural Networks — A single neuron; How parameters change; Layers and nonlinearity

Stage II — AI engineering

Combine components into applications, evaluate reliable outputs, introduce Git/GitHub, and document privacy, uncertainty and limitations.

Core references: CBSE AI Projects Cookbook XI–XII · UNESCO AI Competency Framework for Students · Experience AI: AI Project Cycle and problem solving · GitHub Skills: Introduction to GitHub

  1. Week 10: Integrated AI Systems I — How AI applications are assembled; Software engineering for AI; Git and GitHub I
  2. Week 11: Integrated AI Systems II — Data pipelines; Forecasting and monitoring; GitHub II: reproducible projects
  3. Week 12: Language Models and Trust — Inside a language model; Reliable evaluation; Responsible use and project design

Stage III — competition projects

Translate a task specification into a reproducible baseline, controlled improvements, and a working technical demonstration.

Core references: IOAI 2026 Syllabus · Romanian Artificial Intelligence Olympiad (ONIA) · IOAI 2026 Official Tasks and Solutions · Polish AI Olympiad: high-school training

  1. Week 13: FIICode: Baselines and Metrics — Reading competition specifications; Reproducible baselines; Team project organisation
  2. Week 14: FIICode: Error Analysis and Tuning — Error analysis; Experiments that count; GitHub collaboration
  3. Week 15: FIICode: Mock Hackathon — Complete AI solution; Valid results and communication; Software handover and next steps

About syllabus granularity

The Romanian programme directly describes Python, supervised/unsupervised learning, KNN, K-Means and linear regression. ID3 entropy, convolution internals, multilayer neural networks and Git workflows are treated as additional enrichment drawn from specialist learning resources and the IOAI syllabus.
