The four recurring formats

  1. Course: self-contained electronic textbook; numbered sections, definitions, worked code examples, diagrams and bibliography alongside the topic.
  2. Laboratory: external interactive experience first, then guided Colab, experimentation and short reflection. Notebook code is previewed directly on the page.
  3. Homework: brief UAIC-style specification: Context, Mandatory (1p), Homework (2p), Submission. Each activity extends the lab project.
  4. Advanced: printable research-style problem collection, progressive algorithmic reasoning, worked examples and counterexamples. Python is optional, with no verification tools required.
