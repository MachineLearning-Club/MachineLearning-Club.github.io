Assignment 03 — An explainable event planner

Transfer the ID3 algorithm to a new categorical dataset and trace its decisions.

Course Laboratory Homework Advanced

Version 2026–2027 · Individual work · Adapt the Week 3 ID3 implementation

Context

A student club has to decide whether an equipment demonstration should be held in a courtyard or inside. Its archive contains examples with three categorical observations: sky (sunny/cloudy/rainy), wind (calm/windy) and temperature (warm/cold). Historical decisions were recorded as yes (outdoors) or no (indoors).

This is synthetic training data for an algorithm exercise, not a real outdoor-safety decision system.

Resources: Course · Laboratory · Starter ID3 notebook · Club events dataset (12 records).

Mandatory (1p)

  1. Load the new dataset into the ID3 notebook without changing the original algorithm.
  2. Reserve the records with numbers 4, 7 and 11 for evaluation. Do not train on those three records.
  3. Calculate the root information gains on the nine training records and select the best question.
  4. Draw the learned tree, predict the three held-out answers, and report how many were correct.

Homework (2p)

  1. Add a function that prints the decision path for one prediction (for example, sky = cloudy → wind = calm → yes).
  2. Handle an unseen category such as sky = foggy by reporting the fallback label and an explicit warning.
  3. Compare the root question with the question chosen by a simple human rule. Explain whether both approaches give the same predictions on the evaluation records.
  4. Include an explanation of one limitation of training on such a small dataset.

Advanced — optional reading

Open the ID3 reasoning problem sheet: minimal trees, irrelevant attributes, missing combinations, and why a learned tree is only as justified as the information available. No additional software is needed.

Submission

Submit the modified Colab notebook or .ipynb file, a labelled tree diagram, and a short results table. GitHub remains optional until the engineering part of the course.
