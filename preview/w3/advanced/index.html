Advanced 03 — The structure of an ID3 tree

Worked examples, minimality arguments and counterexamples.

Course Laboratory Homework Advanced

Algorithmic reasoning exercises

A small A4 exercise sheet inspired by the progression of Ciortuz's ID3 problems: start with a worked calculation; build a tree; justify a minimality claim; study an irrelevant attribute; and construct a counterexample using an incomplete training set.

Everything can be solved using an eight-row table, elementary calculations and pseudocode. Python is permitted only as a way to check a calculation or enumerate the finite cases.

Read exercise sheet (PDF) · LaTeX source · Accessible print version.

Connection with the course

The Course teaches how ID3 picks a split; the Advanced questions ask why that choice works on this dataset and which stronger conclusions cannot be deduced from training accuracy alone. Reasoning—not installation or formal-verification tooling—is the objective.
