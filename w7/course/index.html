7.1. Why would a neural network need hidden neurons?

Core idea

Several simple neurons can combine their answers into a more complex decision. A hidden layer transforms the input before a final neuron makes its prediction.

In Week 6, the four XOR examples could not be separated using one line. Rather than finding a special line that does not exist, combine two simpler Boolean detectors. Define a hidden unit that recognises OR and a second one that recognises AND.

x₁x₂h₁ = ORh₂ = ANDXOR target

OR is true when at least one input is true. AND is true only when both are true. XOR is the situation where OR is true but AND is false: XOR = OR AND NOT(AND).

Check before continuing

For input (1,1), both OR and AND are 1, so XOR must be 0. For (1,0), OR=1, AND=0, so XOR=1.

7.2. Trace a two-layer network, not just the final answer

We can represent this logic using threshold neurons. Let step(z)=1 if z≥0, otherwise 0.

Three simple neuronsh₁ = step(x₁ + x₂ − 0.5)   (OR)h₂ = step(x₁ + x₂ − 1.5)   (AND)ŷ = step(h₁ − 2h₂ − 0.5)   (XOR)

Worked forward pass for (1,1)

  1. First hidden neuron: 1+1−0.5=1.5 → h₁=1.
  2. Second hidden neuron: 1+1−1.5=0.5 → h₂=1.
  3. Output neuron: 1−2×1−0.5=−1.5 → output=0.
  4. Correct: XOR(1,1)=0.

Choose the two input bits to follow every arrow

How do we know this network works on all four inputs?

Run the four truth-table rows through the formulas. The final outputs are 0, 1, 1, 0. This demonstrates representational ability: a working set of weights exists. It does not yet explain how a network would discover those weights during training.

7.3. A smooth activation makes gradual learning possible

A threshold jumps suddenly from 0 to 1. For gradient-based training, we often choose a smooth function so a small weight change causes a small output change. The sigmoid is one example:

Standard logistic sigmoid and squared lossσ(z) = 1/(1+e−z)L = ½(t−ŷ)²σ(0)=0.5. L is zero for a perfect numerical prediction and positive when output differs from target.

A prediction and its loss

Suppose a smooth neuron receives input x=1, starts at w=0, b=0 and should predict t=1.

  1. z=wx+b = 0×1+0=0.
  2. ŷ=σ(0)=0.5.
  3. L=½(1−0.5)²=0.125.

Unlike a hard 0/1 threshold output, 0.5 tells us the numerical activation is in between. It is not automatically a calibrated real-world probability; here it is simply the chosen function's output.

7.4. Adjust one parameter to reduce the error

Gradient descent changes a parameter in the direction that reduces the loss. The derivative is a numerical description of the slope. For the one-weight sigmoid example (with input x=1),

Gradient step for this one neurondL/dw = (ŷ−t) × ŷ(1−ŷ) × xwnew = w − η(dL/dw)

Work out the first update with η=0.4

  1. Prediction 0.5 and target 1 mean ŷ−t=−0.5.
  2. Sigmoid slope at 0 is ŷ(1−ŷ)=0.25.
  3. Gradient −0.5×0.25×1=−0.125.
  4. New weight 0−0.4×(−0.125)=0.05.
  5. New prediction σ(0.05)≈0.5125; new loss ≈ 0.1188—lower than 0.125.

Replay one learning step

For larger learning rates, a step need not always improve the loss; direction and step size both matter. The one-step example is deliberately chosen so the arithmetic is understandable.

7.5. Why is the algorithm called backpropagation?

For a multilayer network, every weight influences the final prediction through intermediate outputs. During the forward pass we calculate neuron outputs left to right. During backpropagation we use the chain rule to calculate how the final error depends on weights, from the output layer backwards.

Forward

Input x → hidden activations h → predicted output ŷ → loss L

Backward

Start with how L changes when output changes, then pass the sensitivity backwards through each connection.

Update

Change all relevant weights with a learning rate, then evaluate again.

FOR each training example:
    FORWARD: compute hidden values, output and loss
    BACKWARD: compute output gradient, then hidden gradients
    UPDATE: move each weight opposite its gradient
Optional formal connection to Ciortuz's derivation

In a two-layer network with standard sigmoid σ and squared loss, output sensitivity is proportional to (output−target)×σ′(net_output). A hidden unit receives that output sensitivity multiplied by its outgoing weight, then by σ′(net_hidden). Ciortuz, §6.1.3, solved problem 20 (printed pp. 789–792), derives the formula with a generalized sigmoid. This standard logistic formula corresponds to choosing the source's parameter c=−1. The full derivation belongs in Advanced.

7.6. Train, evaluate, and notice what could go wrong

A small network has many adjustable numbers, so it may fit a tiny training set perfectly while failing to generalise. Keep evaluation data separate, compare loss across epochs and look for a growing gap between training and validation performance.

ObservationPossible interpretationNext question
Training loss decreasesThe model fits training data betterDoes validation also improve?
Training improves but validation worsensPossible overfittingWould a simpler model help?
Loss fluctuates wildlyLearning rate may be too largeCan a smaller rate stabilise it?
All outputs look similarModel may not learn relevant distinctionsAre the inputs and labels informative?

Week 7 gives conceptual foundations for subsequent image classification. Students do not yet need to train a large network on photographs to understand its key steps.
