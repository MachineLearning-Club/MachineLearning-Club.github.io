Week 07 · Laboratory

Neural Networks and Training

Combine neurons into layers and watch a tiny network improve.

Lab challenge

Train a small network to recognise a toy XOR-like handwritten-symbol pattern.

1. Open an interactive experiment

Launch Neural Network Playground

Observe the example first. Predict one change before adjusting any parameter.

2. Run the guided Python experiment

  1. Try XOR with no hidden layer and record the result.
  2. Add hidden neurons in the visual playground.
  3. Run the notebook and plot training loss over iterations.
  4. Change the learning rate and compare convergence.

Research (3p) (optional)

Compare two network sizes and explain overfitting risk using the same training data.

How to approach this investigation
  1. Start from the working lab code.
  2. Change one thing and keep a record of the original result.
  3. Explain what the new result shows and where it might be misleading.
