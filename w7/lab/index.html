Linear Regression

Fit a straight line to predict numbers and measure errors.

3 Feb 2027One weekly session · 60 minutes
CourseLaboratoryHomeworkAdvanced

Laboratory learning objectives

  1. Plot measurements
  2. Fit a line in Python
  3. Calculate residuals and MSE

Guided laboratory tasks

  1. Plot temperature and sales observations
  2. Fit a linear regression model
  3. Compute residuals and compare in-range versus extrapolated predictions

Work using PRIMM: Predict, Run, Investigate, Modify, Make. Starter code and AI assistance are allowed if you can explain the result.

Evidence to keep

A concise worked calculation, a code/notebook result, and a written explanation of one error or limitation.
