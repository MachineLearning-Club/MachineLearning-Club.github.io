Neural Networks and Training

Combine neurons into layers and watch a tiny network improve.

Real-life situation

A handwriting app confuses two simple symbols because their features overlap.

Mandatory (1p)

Calculate one neuron activation and loss.

Suggested starting steps
  1. Open the Week 7 Laboratory and run the prepared code.
  2. Identify the relevant input and output.
  3. Change the smallest amount of code needed to solve the situation.

Homework (2p)

Change the hidden layer size in the supplied notebook and compare accuracy.

What to submit

Use the laboratory submission area to prepare a named notebook or Python file. Add one screenshot, output table or short explanation of what changed.
