Week 07 · Homework

Neural Networks and Training

Situation — recognise a two-bit pattern

Your first single-neuron classifier could not solve XOR. A network with two hidden Boolean detectors can express it. Separately, a smooth sigmoid neuron can move its weights to reduce a numerical error. Your task is to distinguish representation from training.

Mandatory (1p) — trace the full network

  1. For input (x₁,x₂)=(1,0), calculate h₁=step(x₁+x₂−0.5) and h₂=step(x₁+x₂−1.5).
  2. Calculate ŷ=step(h₁−2h₂−0.5) and compare it with XOR(1,0).
  3. Repeat the forward pass for (1,1), showing both hidden sums, not only final output.
  4. For a separate smooth neuron with x=1,w=0,b=0,t=1, calculate sigmoid output, squared loss, gradient and updated weight at η=0.4.
Check the results

(1,0): h₁=1, h₂=0, output=1. (1,1): h₁=1,h₂=1,output=0. Smooth-neuron step: output 0.5, loss 0.125, gradient −0.125, new weight +0.05.

Homework (2p) — compare two learning steps

  1. Open the two-layer gradient notebook and execute its provided forward pass.
  2. Show the hidden output, final output and loss before the first update. Identify which weights influence the loss through the hidden neuron.
  3. Verify one gradient by changing its weight by a tiny amount (finite-difference calculation is provided).
  4. Run five update steps for learning rates 0.1 and 0.5, recording both output and loss.
  5. Explain why a decrease in training loss does not prove a network will perform well on an unseen image.

All data are invented and numeric. Full image-classification training is deliberately outside this 60-minute introduction.

Research (3p) — optional

Derive the chain-rule gradients for the one-hidden-neuron network h=σ(w₁x), ŷ=σ(w₂h), L=½(t−ŷ)². Show that ∂L/∂w₂=(ŷ−t)ŷ(1−ŷ)h and ∂L/∂w₁=(ŷ−t)ŷ(1−ŷ)w₂h(1−h)x. Compare them against the notebook's numerical gradients.

What to submit

Submit the hand calculation for two XOR inputs, one sigmoid update, and a notebook containing the before/after loss table. Use Week 7 Laboratory to prepare a named file locally.
