Week 15 · Homework

FIICode IV: Hackathon

A real challenge, a functioning application and an evidence-based presentation.

Real-life situation

A real hackathon team must hand over code and demonstrate what its solution does.

Mandatory (1p)

Submit a reproducible build or notebook with a README.

Suggested starting steps
  1. Open the Week 15 Laboratory and run the prepared code.
  2. Identify the relevant input and output.
  3. Change the smallest amount of code needed to solve the situation.

Homework (2p)

Provide a brief demo, validation evidence and an honest limitations section.

What to submit

Use the laboratory submission area to prepare a named notebook or Python file. Add one screenshot, output table or short explanation of what changed.
