Week 15 · Homework

FiiCode IV: Reproduce, Present and Hand Off

Teacher Guide One 60-minute session; core + optional Research

Learning outcome

Run a single final test with frozen settings; demonstrate and communicate reproducibility.

Teaching sequence

0–13 freeze configuration; 13–25 reveal hold-out results; 25–45 demonstrate application and tests; 45–55 peer review; 55–60 hand-off.

Core: reproducible observations, one experiment and an explanation in ordinary language. Research (3p): additional mathematics, model investigation or application engineering. All features and labels in this project are synthetic; do not infer student traits or real room conditions.

Independent preparation project: these are deliberately simulated examples for practising data analysis and software engineering. They are not official FiiCode rules, datasets, judging criteria or submissions.

The same study-space dataset, baseline and application are used in every homework from Week 12 to Week 15. Submit evidence, not just a final number.

Project starter ZIPProblem and file layout

Mandatory — hand-off specification (1p)

Submit a README.md with the problem, five features, three labels, synthetic origin, 150/45/45 split, instructions to run python evaluate.py and the fixed chosen setting k=1.

Acceptance: a classmate can reproduce the result with the project ZIP and a normal Python installation, without API keys.

Homework — tested final demo (2p)

Deliver the working application and evidence.md documenting the final 38/45 result, confusion matrix, one case of failure, three software tests and one real limitation. Include a 2–3 minute demonstration plan and evidence that the tests ran.

Acceptance: reproducible program, traceable measurements and no claims that the synthetic benchmark reflects actual classrooms. Use the project rubric.

Research — follow-up evaluation design (3p, optional)

Describe how a future school trial would collect consensual, anonymised feedback, distinguish subjective preferences and assess whether the system works under different conditions. No real personal or location data should be collected for this assignment.

Delivery contract

Produce the named files, record original and modified results, and export them through the corresponding Laboratory submission panel. The named ZIP is prepared locally; teacher collection is a separate step.
