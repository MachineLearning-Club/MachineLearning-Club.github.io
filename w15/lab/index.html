Week 15 · Laboratory

FIICode: Mock Hackathon

Demonstrate a complete solution and defend its limitations.

7 Apr 2027One weekly session · 60 minutes
CourseLaboratoryHomeworkAdvanced

Laboratory learning objectives

  1. Run a reproducible demonstration
  2. Test normal and unusual cases
  3. Collect peer feedback

Guided laboratory tasks

  1. Run the full model from setup notes
  2. Present the baseline model and failure case in three minutes
  3. Collect feedback and prioritise fixes

Work using PRIMM: Predict, Run, Investigate, Modify, Make. Starter code and AI assistance are allowed if you can explain the result.

Evidence to keep

A concise worked calculation, a code/notebook result, and a written explanation of one error or limitation.
