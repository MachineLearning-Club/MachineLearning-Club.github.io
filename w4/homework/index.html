Week 04 · Homework

Revision: Supervised and Unsupervised Learning

Revision challenge — explain what you already know

A school wants to predict whether an outdoor activity can take place, group parcel locations into collection zones, and classify a new player from labelled examples. These are three different questions. Your job is to select and justify a method, not simply run a library.

Mandatory (1p) — reconstruct the essentials

  1. ID3: from the Week 2 twelve-row diary, calculate the information gain of Sky using [6+,6−] before the split and [4+,0−], [2+,2−], [0+,4−] afterward. Draw the learned tree.
  2. K-means: given the five Week 3 points and starting centroids A(−1,0), E(3,1), write the first two clusters and their new means.
  3. Algorithm selection: state whether known labels are required for each of ID3, K-means and KNN.
  4. Evaluation: from TP=2,TN=2,FP=1,FN=1, compute test accuracy and describe one limitation of six test records.
Solution check after attempting

ID3 gain 2/3; tree Sky→sunny yes, rainy no, cloudy→Wind (calm yes, windy no). K-means centres (0,1/3) and (3,1/2). ID3 and KNN need known training labels; K-means does not. Test accuracy 4/6≈66.7%, which is not a reliable real-world performance estimate.

Homework (2p) — build a small revision report

  1. Open the prepared notebook and rerun its provided calculations.
  2. Consider new point Q(2,2) with class-A examples (1,1),(1,2),(2,1) and class-B examples (4,4),(4,5),(5,4). Calculate all six squared distances. Classify Q using KNN with K=3.
  3. Create a table with four rows (ID3, K-means, KNN, confusion matrix). For each give the required inputs, output and one limitation.
  4. Change one test result from correct to incorrect. Recalculate accuracy. Explain why training accuracy cannot replace this check.
  5. Write a concise reflection: which part of Week 2 or Week 3 remains hardest, and what computation would you practise again?

Research (3p) — optional comparison

Design a data set on which KNN (supervised majority vote) and K-means (unsupervised two-centroid grouping) put a new point into visibly different regions. State what each algorithm is being asked to do and why their outputs should not be compared as if they were identical labels.

What to submit

One revision notebook or PDF with your handwritten ID3 gain, centroid calculation, KNN distance table, confusion matrix and reflection. Use the laboratory download-preparation area.
