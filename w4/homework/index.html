Week 04 · Homework

Revision: Supervised and Unsupervised Learning

Compare ID3, K-Means and K-nearest neighbours on one small dataset.

Real-life situation

A school sports club must classify a new participant and separately group existing participants into training sessions.

Mandatory (1p)

Explain which method serves each of the two needs.

Suggested starting steps
  1. Open the Week 4 Laboratory and run the prepared code.
  2. Identify the relevant input and output.
  3. Change the smallest amount of code needed to solve the situation.

Homework (2p)

Modify the lab KNN code to classify new points and compare K=1 vs K=3.

What to submit

Use the laboratory submission area to prepare a named notebook or Python file. Add one screenshot, output table or short explanation of what changed.
