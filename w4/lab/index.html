4. Reproduce a held-out test result

Assume six test cases with TP=2, TN=2, FP=1, FN=1. Compute accuracy, then imagine swapping one correct prediction for one false positive.

Why count both kinds of errors?

False positives and false negatives can have different consequences. We use simple six-row data only to practise the meaning of each count, not to estimate actual model performance.
