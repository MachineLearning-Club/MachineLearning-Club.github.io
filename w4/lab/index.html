Numeric Splits and Evaluation

Continuous features, unseen data, accuracy and confusion matrices.

13 Jan 2027One weekly session · 60 minutes
CourseLaboratoryHomeworkAdvanced

Laboratory learning objectives

  1. Try threshold candidates
  2. Evaluate a held-out sample
  3. Explain false positives and negatives

Guided laboratory tasks

  1. Try midpoints between sorted numeric values
  2. Evaluate predictions on a holdout
  3. Analyse a false-positive and false-negative example

Work using PRIMM: Predict, Run, Investigate, Modify, Make. Starter code and AI assistance are allowed if you can explain the result.

Evidence to keep

A concise worked calculation, a code/notebook result, and a written explanation of one error or limitation.
