Week 04 · Advanced

Revision: Supervised and Unsupervised Learning

A revision built around reasoning, not definitions

Try each question independently, then open its solution. The problems reuse the precise numerical examples from Weeks 2 and 3 and introduce only a short supervised-neighbour comparison. No machine-learning library is required.

Five worked challenges

1. When does a feature contain no information?

Given [6+,6−], a candidate split creates two groups of [3+,3−]. Calculate the weighted entropy and information gain. What happens if a feature always splits the data in the same proportions?

Hint

The two branches each have the same relative label frequencies as the parent.

Solution

Parent H=1. Both child groups have H=1 and weight 6/12. Thus H(after)=1 and IG=0. The feature has not changed the label uncertainty.

2. Why weight entropy by branch size?

Suppose a dataset has ten labels, five positive and five negative. A question creates [5+,4−] and [0+,1−]. Evaluate conditional entropy and compare with the incorrect unweighted average.

Solution

H([5+,4−])≈0.991. Weighted conditional entropy is 9/10×0.991+1/10×0≈0.892, so gain ≈0.108. An unweighted average would give 0.496 and spuriously suggest gain 0.504. Nine rows cannot have the same weight as one row.

3. Can K-means worsen its squared error in one ordinary update?

From groups ABC and DE compute J with old centres A and E, then with their new means. Explain which of the two assignment/update operations is responsible for reducing the sum of squared distances.

Solution

Old cost 7, new cost 19/6. For a fixed group the mean minimises squared distance. Assigning each point to its nearer current centroid cannot increase the objective either. This is a local monotonicity statement, not a proof of globally optimal clusters.

4. Class voting is not the same as clustering

Point Q=(2,2) has labelled neighbours A at (1,1),(1,2),(2,1), and B at (4,4),(4,5),(5,4). Compute all squared distances, give the K=3 KNN prediction, then explain why running K-means with K=3 would not produce the same sort of output.

Solution

Squared distances are 2,1,1,8,13,13. Three nearest labels are A, so KNN predicts A. K-means K=3 would try to construct three clusters without consulting these A/B labels; its group number is not a known class.

5. Accuracy can hide an important error pattern

On 20 test examples a model predicts “no” every time. In the ground truth only 2 are positive. Find accuracy, recall for the positive class, and explain why reporting only accuracy would mislead.

Solution

TN=18, FN=2, TP=0, FP=0. Accuracy=(18+0)/20=90%. Positive recall=TP/(TP+FN)=0/2=0%. A classifier can achieve high accuracy by always predicting a common class while finding no positive cases at all.

Teacher note

The optional last problem extends model evaluation beyond this week's core learning goals. Prefer a grounded explanation of false negatives over formula memorisation, and state which class is defined as positive before calculating a metric.
