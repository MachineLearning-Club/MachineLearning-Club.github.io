1. State what the program should do

A school caretaker wants a monitor that shows a warning when a fictional temperature sensor is disconnected. Write expected outputs for three cases: 17 °C, 21 °C and missing input.

Check

17 °C → HEAT ON; 21 °C → HEAT OFF; missing → CHECK SENSOR. These are rules, not ML predictions.

4. Review one change and save it

Open the account-free Git simulation. Edit the miniature program, test it, then commit a meaningful version such as Add missing-sensor warning. Do not create an account unless you want to continue with real GitHub later.

Research (3p) — optional

Write a new component History that remembers the last three fictional readings and prints them. Test that a missing reading is not stored as a real temperature. Explain which existing component needs to know about History, and which should not.

Submission

A notebook with the program, three input/output tests, one before/after code change and an informative commit-message example. No account is required and the submission preparation area does not send files automatically.
