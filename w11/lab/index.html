Integrated AI Systems II

Forecasting, clustering and communicating model quality.

10 Mar 2027One weekly session · 60 minutes
CourseLaboratoryHomeworkAdvanced

Laboratory learning objectives

  1. Clean a small time-series dataset
  2. Compare naive and regression baselines
  3. Create a prediction dashboard

Guided laboratory tasks

  1. Clean chronological demand data
  2. Compare a naive mean with linear regression
  3. Plot actual versus predicted demand with MAE

Work using PRIMM: Predict, Run, Investigate, Modify, Make. Starter code and AI assistance are allowed if you can explain the result.

Evidence to keep

A concise worked calculation, a code/notebook result, and a written explanation of one error or limitation.
