Week 11 · Homework

Software Engineering Techniques

Objects, project structure, testing and simple AI pipelines.

Real-life situation

A classroom monitor should continue to display useful information when a sensor fails.

Mandatory (1p)

Create a Sensor class with a method that returns a reading.

Suggested starting steps
  1. Open the Week 11 Laboratory and run the prepared code.
  2. Identify the relevant input and output.
  3. Change the smallest amount of code needed to solve the situation.

Homework (2p)

Add input validation and a classifier component, then test normal and missing data.

What to submit

Use the laboratory submission area to prepare a named notebook or Python file. Add one screenshot, output table or short explanation of what changed.
