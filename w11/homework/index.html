Week 11 · Homework

Software Engineering Techniques

Situation — a classroom monitor fails when its sensor disconnects

A fictional temperature monitor works for numbers but cannot handle missing values. The caretaker must see “CHECK SENSOR”, rather than a false temperature. This exercise asks you to make one useful software change and prove it works.

Mandatory (1p)

  1. Write the desired output for 17 °C, 21 °C and missing input.
  2. Run the prepared laboratory and find its decide(value) function.
  3. Explain in one sentence why the function has to check value is None before comparing it with 19.
  4. Show one assertion that checks missing-input behaviour.
Answer check

assert decide(None) == "CHECK SENSOR". A numerical comparison with None would fail in Python; the warning branch should run before the comparison.

Homework (2p)

  1. Keep the Sensor class separate from the decision function.
  2. Change the warning threshold from 19 to 20 and update the relevant tests.
  3. Run at least four tests: 17, 19, 21 and None.
  4. Record which files/functions changed and why.
  5. Write a meaningful commit message, even if you save versions only through the club’s account-free simulation.

Research (3p) — optional

Create a Display class that receives only messages, not raw readings. Explain why the Display need not know how Sensor works. Draw a simple 3-box diagram, then add one test for the new class.
