Week 06 · Homework

Perceptrons: A First Learning Neuron

Situation — a sorter learns a Boolean rule

Two binary sensors determine whether a hypothetical recycling-station gate activates. A threshold perceptron must learn the AND rule from four labelled examples. This is a safe simulated control problem, not a device to use in real machinery.

Mandatory (1p) — one neuron, four predictions

  1. For w₁=1,w₂=1,b=−1.5 and step(z)=1 if z≥0 else 0, complete the weighted sum and output for all four input pairs.
  2. Explain geometrically what the equation x₁+x₂−1.5=0 represents.
  3. Start from w₁=w₂=0,b=−1. For one training example (x₁,x₂,t)=(1,1,1) and η=1, compute the prediction, error and new parameters.
  4. Check that the corrected parameters now predict 1 for (1,1). Why is this not yet a guarantee of perfect classification on all four examples?
Check your hand calculation

The initial AND truth table is 0,0,0,1. The boundary is a line. For (1,1), initial z=−1→ŷ=0; t−ŷ=1, so w₁=1,w₂=1,b=0. That fixes one row but may misclassify the others.

Homework (2p) — implement and inspect training

  1. Open the prepared training notebook; first execute it unchanged.
  2. Use the four AND records in the same order. Run for at most 20 epochs; print the mistake count and all three parameters after every epoch.
  3. Compare learning rates η=0.2 and η=0.5. Does each converge within 20 epochs? Do the final parameters have to be identical?
  4. Test one intermediate input (0.75,0.75) and explain that the model is defined on real inputs even though the training truth table contained only bits.
  5. Change only the target labels to XOR [0,1,1,0]. Record evidence that a single line cannot represent them all.

Research (3p) — optional

Write a concise geometric argument showing that the two positive XOR corners and the two negative XOR corners have the same midpoint (0.5,0.5). Explain why this blocks a strict straight-line separator. Then build a two-hidden-unit solution using Week 7's Boolean construction.

What to submit

One notebook with a four-row truth table, one manually calculated update, two training histories and a short XOR explanation. Use Week 6 Laboratory to prepare the local file.
