Week 06 · Homework

Perceptrons: A First Learning Neuron

Understand weights, bias and a decision boundary before a large neural network.

Real-life situation

A recycling station must separate two kinds of objects using simple measurements.

Mandatory (1p)

Compute neuron outputs for three inputs.

Suggested starting steps
  1. Open the Week 6 Laboratory and run the prepared code.
  2. Identify the relevant input and output.
  3. Change the smallest amount of code needed to solve the situation.

Homework (2p)

Modify two weights and a bias in the lab notebook to classify new examples.

What to submit

Use the laboratory submission area to prepare a named notebook or Python file. Add one screenshot, output table or short explanation of what changed.
