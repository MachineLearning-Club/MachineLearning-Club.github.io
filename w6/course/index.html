Teaching sequence

Derive the perceptron from familiar arithmetic and boolean tables, rather than treating a neuron as a biological illustration. Our threshold convention is step(z)=1 if z≥0, else 0, with input/target in {0,1}. 6.1. How could a machine learn a yes/no rule?

Core idea

Input features → weighted sum → threshold → 0 or 1. A perceptron is a small model that can learn to move its decision boundary by changing numerical weights and bias.

Imagine a toy recycling sorter. It receives two simple binary sensor readings: x₁ = 1 if the first condition is met and x₂ = 1 if the second is met. It should activate only when both conditions are met. This is the Boolean AND task and a mathematical teaching example, not an industrial safety system.

Because the correct answer is given for every row, this is supervised learning (compare Week 2). The new question is not how to choose a tree feature, but how to choose numerical parameters for one neuron.

6.2. A neuron is an understandable mathematical function

Weighted sum and thresholdz = w₁x₁ + w₂x₂ + bŷ = 1 when z ≥ 0, otherwise ŷ = 0. Here b is the bias; it shifts the boundary even when inputs are zero.

Choose w₁=1, w₂=1, b=−1.5. The weighted sum is x₁+x₂−1.5.

Compute all four outputs

(x₁,x₂)zstep(z)AND target
(0,0)−1.500
(1,0)−0.500
(0,1)−0.500
(1,1)0.511

The model correctly computes AND. But in a learning problem the values of the weights and bias are initially unknown and must be adjusted from examples.

What is the bias doing?

For w₁=w₂=1 the bias sets how much evidence is needed before the sum reaches zero. With b=−1.5 only the double-1 input passes. With b=−0.5 either single-1 input also passes, so the model acts more like OR.

6.3. Each neuron divides the plane with a straight line

The equation w₁x₁+w₂x₂+b=0 describes a line in the 2D feature plane. On one side the neuron predicts 0; on the other side it predicts 1. Each point (x₁,x₂) corresponds to one observation.

Adjust the parameters of a neuron

InputWeighted sumOutputTarget
Change one thing:

Keep the weights at 1 and move the bias from −1.5 to −0.5. Which of the four predictions changes? What is the new Boolean function on these four inputs?

Answer

Inputs (1,0) and (0,1) change from 0 to 1. The resulting truth table is Boolean OR. The line has shifted toward the origin.

6.4. Learning means correcting mistakes

Core idea

Prediction → compare with target → update weights and bias. A perceptron learning rule uses the error signal t−ŷ. When the prediction is correct, the update is zero.

Per-example perceptron updatewᵢ ← wᵢ + η(t−ŷ)xᵢ;   b ← b + η(t−ŷ)η (“eta”) is a positive learning rate. This is the standard mistake-based update for a threshold classifier with 0/1 targets.

One complete manual update

Start with w₁=0, w₂=0, b=−1. Train on input (1,1) whose target is t=1, with learning rate η=1.

  1. Forward prediction: z = 0×1+0×1−1=−1 → ŷ=0.
  2. Error: t−ŷ=1−0=1.
  3. Updates: w₁'=0+1×1×1=1; w₂'=1; b'=−1+1×1=0.
  4. Predict the same example again: z'=1×1+1×1+0=2 → ŷ=1.
  5. One example is now correct, but this does not prove all four rows are correct. Repeating training on different examples is essential.

Train on all four AND examples



One epoch means one complete pass over the training examples. Depending on their order and the learning rate, more than one pass may be necessary.


6.5. Why a single perceptron cannot learn everything


The output of one threshold perceptron always separates the plane using a straight line. The XOR truth table, however, alternates labels across opposite corners.


x₁x₂XOR target
000
101
011
110


There is no single line placing (1,0) and (0,1) on the positive side while both (0,0) and (1,1) stay on the negative side. This is the key limitation that motivates hidden layers in Week 7.
Optional geometric justification
The midpoint of positive points (1,0) and (0,1) is (0.5,0.5); the midpoint of negative points (0,0) and (1,1) is also (0.5,0.5). Any half-plane containing both positives must contain their midpoint, and any opposite half-plane containing both negatives must also contain that same midpoint. A strict linear separator cannot do both.

Concept transfer · Week 6 to Week 7
6 → 7 · Why one straight line is not enough


The AND model with w₁=1, w₂=1 and b=−1.5 produces weighted sums −1.5, −0.5, −0.5, 0.5 for inputs (0,0), (0,1), (1,0), (1,1). With the convention step(z)=1 when z≥0, the predictions are 0,0,0,1.


Compare AND with XOR
XOR instead requires 0,1,1,0 on the same four inputs. One line cannot isolate the two opposite positive corners from the two opposite negative corners, so no single two-input threshold perceptron represents all four XOR labels correctly.


Why not just train the perceptron longer?
Changing weights still produces a linear boundary. The limitation is the model's expressive form, not simply insufficient training steps. A hidden layer can combine multiple line-like decisions into a nonlinear overall rule.


Week 7 demonstrates XOR using hidden neurons. Its first example uses manually supplied weights to establish representation; a separate smooth-neuron example demonstrates learning by gradient descent.
