Perceptrons: A First Learning Neuron

Teacher Guide Course overview and teaching sequence

Course summary

Understand weights, bias and a decision boundary before a large neural network. This lesson uses a practical classroom situation: An automatic recycling sorter learns whether a sensor reading looks like metal or paper.

By the end: learners should be able to describe each topic using an input, an algorithmic step and an observable result, then run a small Python example and identify one limitation.

1. A neuron computes a weighted sum

1.1. Real-life situation

A sensor measures brightness and reflectance for a recyclable object.

1.2. Understanding the concept

A perceptron multiplies inputs by weights, adds a bias, then applies a simple activation rule.

1.3. Worked example

For x=(2,1), w=(1,-1), bias=-0.5, weighted total=2-1-0.5=0.5.

1.4. Try it in Python

x = [2,1]; w = [1,-1]; bias=-.5
score = sum(a*b for a,b in zip(x,w))+bias
print(score>=0)
See the algorithm step by step
  1. Multiply each input by its weight
  2. Add the bias
  3. Apply the step rule

2. Weights change the decision

2.1. Real-life situation

A sorter mistakes one sample for metal.

2.2. Understanding the concept

Positive and negative weights pull decisions in different directions; the bias shifts the threshold.

2.3. Worked example

Increasing the brightness weight may move some samples to the 'metal' side.

2.4. Try it in Python

def output(x,w,b):
    return int(sum(a*c for a,c in zip(x,w))+b>=0)
print(output([1,1],[1,-1],-.5))
See the algorithm step by step
  1. Change one weight
  2. Predict a border case
  3. Compare old/new decisions

Try this: change one input or value in the code, then predict the new output before running.

3. A perceptron can learn from errors

3.1. Real-life situation

A labelled training example was misclassified.

3.2. Understanding the concept

A basic perceptron update adjusts weights toward the desired label when a mistake occurs. It is not the same as backpropagation through a multilayer network.

3.3. Worked example

For target 1 and prediction 0, a positive learning rate increases weights along the input vector.

3.4. Try it in Python

weights = [0.0,0.0]
x=[1,2]; target=1; prediction=0; lr=.1
print([w+lr*(target-prediction)*xi for w,xi in zip(weights,x)])
See the algorithm step by step
  1. Predict
  2. Compare with label
  3. Apply a small update
