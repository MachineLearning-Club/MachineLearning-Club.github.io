Unsupervised Learning: K-Means

Find groups in data when no class labels have been supplied.

Real-life situation

A parcel service is deciding where to place two collection points for neighbourhood deliveries.

Mandatory (1p)

Calculate the centroid of three given locations.

Suggested starting steps
  1. Open the Week 3 Laboratory and run the prepared code.
  2. Identify the relevant input and output.
  3. Change the smallest amount of code needed to solve the situation.

Homework (2p)

Use the K-Means notebook to cluster new delivery addresses and produce a labelled scatterplot.

What to submit

Use the laboratory submission area to prepare a named notebook or Python file. Add one screenshot, output table or short explanation of what changed.
