3.1. Finding groups when the answers are unknown

Core idea

Unlabelled examples → measure similarity → organise examples into clusters. K-means does not receive correct cluster names during training; it uses distances and centres to discover a grouping.

A neighbourhood delivery company wants two collection points so parcels do not have to travel as far to customers. The map contains five delivery locations. Nobody has said which location belongs to which centre.

Learn how to predict the answer.

Check before continuing

Can K-means tell you whether a delivery location is “good” or “bad”? No. It groups locations based on the features and distance you choose. The algorithm does not know that these are delivery addresses.

We choose K=2 clusters, with the initial centroids μ₁ = (−1,0) and μ₂ = (3,1).

Euclidean distance in two dimensionsd((x,y),(a,b)) = √((x−a)² + (y−b)²)To compare which distance is smaller, we can compare the squared distances and omit the square root. This does not change the nearest centre.

Worked example — where should B(1,0) belong?

  1. Distance from B to μ₁: √((1−(−1))²+(0−0)²) = 2.
  2. Distance from B to μ₂: √((1−3)²+(0−1)²) = √5 ≈ 2.24.
  3. 2 is smaller than √5, so B belongs to cluster 1 in the first assignment.

3.3. K-means is an alternating process

Instead of guessing a complete grouping once, K-means alternates two steps: assign every point to its closest centre, then update each centre to the mean of its assigned points.

INTERACTIVE RECONSTRUCTION OF CIORTUZ, SOLVED PROBLEM 7
Start

PointDistance² to μ₁Distance² to μ₂Assigned group

Worked — recomputing the two centres

  1. The first group contains A(−1,0), B(1,0), C(0,1).
  2. Average the x coordinates: (−1+1+0)/3 = 0. Average the y coordinates: (0+0+1)/3 = 1/3.
  3. So the new centre is μ₁ = (0,1/3).
  4. The second group is D(3,0), E(3,1); its mean is μ₂ = (3,1/2).
How to find a centroidcentroid = (average x coordinate, average y coordinate)This is just the familiar arithmetic mean, applied independently to each coordinate.
What does one complete K-means iteration mean?

One iteration consists of assigning each point to its nearest current centroid and moving each centroid to the mean of its assigned points. The next iteration uses those updated positions for reassignment.

3.4. How can we tell the centres improved?

We measure the total squared distance of every point from its assigned centroid. Call this J or the within-cluster sum of squares.

Objective functionJ = Σ [ (xᵢ−μₓ)² + (yᵢ−μᵧ)² ]Sum over all points, using the centroid to which each point is currently assigned.

Numerical comparison from the source example

Using the initial centroids and first assignments, the total squared distance is:

J(before update) = 0 + 4 + 2 + 1 + 0 = 7.

After recomputing the means, the squared distances become:

10/9 + 10/9 + 4/9 + 1/4 + 1/4 = 19/6 ≈ 3.167.

The cost has decreased: 7 → 3.167.

The update to the arithmetic mean reduces (or leaves unchanged) the sum of squared distances for the current cluster. Reassignment to a nearer centre also cannot increase that sum. See Advanced for the reasoning.

3.5. Continue until the assignments stop changing

With new centres, check all five points again. In this example, the two groups stay the same. Their means stay the same too, so the algorithm converges (stops changing).

CHOOSE K initial centroids
REPEAT:
    ASSIGN every point to its nearest centroid
    UPDATE each centroid to the mean of its group
UNTIL no point changes group (or the centroids stop moving)

Real implementations also need a maximum iteration count, an explicit strategy for empty clusters, and a consistent way to handle points exactly equidistant from two centres.

Why does the algorithm have to stop on this small example?

The total squared distance never increases for ordinary assignment/update steps, and here the second assignment is identical to the first. Recomputing the means therefore changes nothing. More generally, the finite number of possible assignments helps explain termination under suitable deterministic tie handling.

3.6. K-means does not always find the “right” groups

ChoiceWhy it matters
K (number of groups)The algorithm will create the number you request, even if reality has a different number
Starting centroidsDifferent starting positions can converge to different solutions
Feature units / scaleOne large-number feature can dominate distance
OutliersA faraway point can pull a mean away from most others
Shape of the dataCurved or interlocking groups may not be handled meaningfully by ordinary K-means

Clusters are a model of similarity, not automatically real-world categories or proof that one location is important. Students must ask: does the mathematical distance represent the practical problem?

What if we measure metres in one feature and kilometres in the other?

Euclidean distance depends on scale. Convert to consistent units before clustering; otherwise the larger numerical scale can dominate, even if it is not more important.
