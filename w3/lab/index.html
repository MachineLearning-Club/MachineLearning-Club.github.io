Week 03 · Laboratory

Unsupervised Learning: K-Means

Find groups in data when no class labels have been supplied.

Lab challenge

A city courier wants two collection zones from six delivery coordinates.

1. Open an interactive experiment

Launch Visualizing K-Means (move centres)

Observe the example first. Predict one change before adjusting any parameter.

2. Run the guided Python experiment

  1. Plot six delivery points on a grid.
  2. Manually calculate the centre for one proposed cluster.
  3. Open the K-Means visualisation; change the starting centres.
  4. Run the supplied notebook and compare its final grouping to your guess.

Research (3p) (optional)

Find a point arrangement where K=2 produces a misleading grouping.

How to approach this investigation
  1. Start from the working lab code.
  2. Change one thing and keep a record of the original result.
  3. Explain what the new result shows and where it might be misleading.
