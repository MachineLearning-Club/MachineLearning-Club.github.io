Decision Trees: ID3

Decision-making by splitting categorical data using information gain.

CourseLaboratoryHomeworkAdvanced

Laboratory objectives

  • Compute candidate split scores
  • Draw a two-level decision tree
  • Trace new samples through the tree

Lab activities

  1. Count labels and calculate candidate information gains
  2. Draw the best root split and a second level
  3. Fit a comparison tree in scikit-learn and explain differences

What to record

Record a worked example, a tested result and one limitation. Use PRIMM: Predict, Run, Investigate, Modify, Make.
