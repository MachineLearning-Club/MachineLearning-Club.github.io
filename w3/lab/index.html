Week 03 · Laboratory

Decision Trees: ID3

Decision-making by splitting categorical data using information gain.

16 Dec 2026One weekly session · 60 minutes
CourseLaboratoryHomeworkAdvanced

Laboratory learning objectives

  1. Compute candidate split scores
  2. Draw a two-level decision tree
  3. Trace new samples through the tree

Guided laboratory tasks

  1. Count labels and calculate candidate information gains
  2. Draw the best root split and a second level
  3. Fit a comparison tree in scikit-learn and explain differences

Work using PRIMM: Predict, Run, Investigate, Modify, Make. Starter code and AI assistance are allowed if you can explain the result.

Evidence to keep

A concise worked calculation, a code/notebook result, and a written explanation of one error or limitation.
