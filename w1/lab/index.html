Week 01 · Laboratory

What Is AI? Rules and Learning

Rules, search, learning from examples and language.

Lab challenge

Teach an image model with two classroom objects, then compare it with a fixed-rule thermostat.

Laboratory objectives

Experience an AI prediction, train a two-class model using ordinary objects, and inspect a much smaller Python model to see what learning actually changes.

1. Explore — Quick, Draw!

Play two or three rounds. Before finishing a sketch, watch the changing guesses. Record one correct and one incorrect guess. Do not assume it recognises the object in the same way a human does.

Launch Quick, Draw! ↗

  1. Choose one drawing the system guessed quickly.
  2. Choose one it failed to recognise.
  3. Suggest a difference between the training sketches and yours.

Source: Experiments with Google — AI collection.

2. Experiment — Teachable Machine

Use two ordinary classroom objects (for example, a pencil case and a notebook), not students' faces. Collect about ten different camera frames for each object. Train a model and test on a new background.

Launch Teachable Machine ↗

  1. Collect and label examples of A and B.
  2. Train the image classifier.
  3. Test each object at least three times on backgrounds that were not used for training.
  4. Record the predicted class and whether it was correct. What changed?

Teachable Machine uses a more complicated underlying model than the toy Python classifier. Do not try to interpret its displayed scores as calibrated probabilities.
