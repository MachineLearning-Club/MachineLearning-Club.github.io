Probability and Expected Value — Advanced

Optional mathematical extensions: conditional probability, Bayes' theorem, expected value and interpreting evidence.

Mathematical reference

Let X be the face of a ten-sided die, with possible values 1 to 10. When the die is fair, all ten faces have probability 0.1.

Formulas

Equally likely outcomesP(A) = |A| / |Ω|
Conditional probabilityP(A | B) = P(A ∩ B) / P(B)
Bayes' theoremP(A | B) = P(B | A) P(A) / P(B)
Expected valueE[X] = Σ x · P(X=x)
VarianceVar(X) = E[X²] − (E[X])²

Worked example — a rigged die with a deceptive average

A ten-sided die has probabilities P(1) = P(10) = 0.30 and P(2) = … = P(9) = 0.05.

E[X] = (1 + 10) × 0.30 + (2 + ⋯ + 9) × 0.05 = 5.50

A fair ten-sided die also has E[X] = 5.50, but the two distributions are different. Equal expected values do not imply equal distributions.

Problems

1. Conditional probability

Roll a fair ten-sided die. Define A = “the roll is 2” and B = “the roll is even”.

  1. Write down A, B and A ∩ B.
  2. Calculate P(A), P(B), P(A ∩ B) and P(A | B).
  3. Explain the meaning of the denominator in P(A | B).
Hint

The even-number condition leaves five possible faces.

Show solution

a) A = {2}, B = {2,4,6,8,10}, A∩B = {2}. b) P(A) = 1/10, P(B) = 1/2, P(A∩B)=1/10, P(A | B) = (1/10)/(1/2) = 1/5. c) It represents the restricted set B in which the result must lie.

2. Who knew the answer?

A student knows the answer to a true/false question with probability 0.4; otherwise, the student guesses. Knowing guarantees correctness, while guessing has probability 0.5 of correctness.

  1. Calculate P(correct).
  2. Find P(knew | correct) using Bayes' theorem.
  3. Repeat if the prior P(knew) is 0.8. Explain how the prior changes the answer.
Hint

P(correct) = P(correct | knew)P(knew) + P(correct | guessed)P(guessed).

Show solution

a) 1 × 0.4 + 0.5 × 0.6 = 0.7. b) 0.4/0.7 = 4/7 ≈ 0.5714. c) P(correct)=0.8+0.1=0.9 and P(knew | correct)=0.8/0.9=8/9 ≈ 0.8889.

3. Compare two expected values

For a fair ten-sided die P(x) = 0.1. For a loaded die P(1) = 0.55 and P(2) = … = P(10) = 0.05.

  1. Check that each distribution sums to 1.
  2. Calculate E[X] for both dice.
  3. Find the expected sum after 30 independent rolls of each die.
Hint

Use E[X] = Σ xP(x) and E[X₁+⋯+X₃₀] = 30E[X].

Show solution

a) 10×0.1=1 and 0.55+9×0.05=1. b) Fair E[X]=5.5; loaded E[X]=0.55+0.05×54=3.25. c) Fair: 165; loaded: 97.5.

4. Same mean, different spread

Compare the fair ten-sided die with the tricky die from the worked example.

  1. Show that both have expected value 5.5.
  2. Calculate E[X²] and variance for each die.
  3. Which distribution is more spread out?
Hint

For the fair die, the sum of squares 1² + 2² + … + 10² is 385. Use Var(X) = E[X²] − E[X]².

Show solution

a) Both E[X] = 5.5. b) Fair E[X²]=38.5 and Var(X)=38.5−30.25=8.25. Tricky E[X²]=0.30×(1²+10²)+0.05×(2²+…+9²)=44.5 and Var(X)=44.5−30.25=14.25. c) The tricky die has larger variance, because extreme values are much more likely.

5. Use Bayes' theorem to investigate a die

A seller says that 20% of their ten-sided dice are loaded. The loaded type has P(1)=0.55; a fair die has P(1)=0.10. You choose one die at random and roll a 1.

  1. Calculate the probability of observing a 1.
  2. Find the posterior probability that the chosen die is loaded.
  3. Why does observing one 1 not prove that the die is loaded?
Hint

Let L = “die is loaded” and R = “roll is 1”. Use P(L | R) = P(R | L)P(L)/P(R).

Show solution

a) P(R) = 0.55×0.2 + 0.10×0.8 = 0.19. b) P(L | R) = (0.55×0.2)/0.19 = 11/19 ≈ 57.9%. c) A fair die can also produce 1, so the evidence is informative but not decisive.

Connection to machine learning

Probability models uncertainty. Bayes' theorem updates beliefs when evidence arrives. Expected value gives a weighted average, but different distributions can have the same average. This is why checking only a model's mean output can hide important differences.
