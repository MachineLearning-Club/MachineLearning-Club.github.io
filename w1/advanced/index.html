Week 01 · Advanced

Information Theory — Advanced Problems

Optional mathematics: surprise, entropy, conditional entropy, and information gain.

Before you begin

These exercises build on Week 1's probability and information-theory foundations. Use logarithms in base 2; write all information measures in bits.

Formula reference

SurpriseI(x) = −log₂ P(x)
EntropyH(X) = −Σ p(x) log₂ p(x)
Conditional entropyH(Y | X) = Σ p(x) H(Y | X=x)
Information gainIG(Y; X) = H(Y) − H(Y | X)

By convention, 0 log₂ 0 = 0.

Worked example — a biased coin

A coin comes up heads with probability 3/4 and tails with probability 1/4. Its entropy is:

H = −(3/4) log₂(3/4) − (1/4) log₂(1/4) ≈ 0.811 bits

A fair coin would have 1 bit of entropy. This biased coin is more predictable, so its entropy is lower.

Problems

1. How surprising is an event?

Compute the information content of events with probabilities 1/2, 1/8, and 1/16. Which is most surprising, and why?

Hint

For probability 1/2k, the surprise is exactly k bits.

Show solution

I(1/2) = 1 bit; I(1/8) = 3 bits; I(1/16) = 4 bits. The rarest event, probability 1/16, carries the most information when observed.

2. Uncertainty in a binary process

Find the entropy when P(A) equals 0, 1/2, 3/4, and 1. Sketch how the entropy depends on p.

Hint

Use H(p) = −p log₂ p − (1 − p) log₂(1 − p). For p = 0 or 1, apply the 0 log₂ 0 convention.

Show solution

H(0) = 0; H(1/2) = 1; H(3/4) ≈ 0.811; H(1) = 0 bits. The curve is symmetric about p = 1/2 and peaks at 1 bit.

3. What does knowing one die tell you?

Two independent fair dice are rolled, and S is the sum. The entropy before seeing either die is approximately 3.2744 bits.

  1. After learning that the first die shows 4, which six values can S take?
  2. Calculate H(S | first die = 4).
  3. Calculate how much uncertainty this observation removes.
Hint

The six remaining possible sums are equally likely.

Show solution

a) The possible sums are 5, 6, 7, 8, 9, 10. b) H = log₂6 ≈ 2.585 bits. c) 3.2744 − 2.585 ≈ 0.6894 bits.

4. Does a feature carry information?

A dataset contains eight labelled examples, four in class A and four in class B. Consider two candidate attributes:

Feature valueClass AClass B
Feature P = 040
Feature P = 104
Feature Q = 022
Feature Q = 122
  1. Find the entropy of the class label before considering a feature.
  2. Find the remaining class entropy when feature P is known.
  3. Repeat for feature Q. Which feature has greater information gain?
Hint

A group containing only one class has entropy 0; an evenly mixed A/B group has entropy 1 bit.

Show solution

Initially H(class) = 1 bit. P creates two pure branches, so H(class | P) = 0 and IG = 1 bit. Q creates two evenly mixed branches, so H(class | Q) = 1 and IG = 0. Feature P is more informative.

5. Joint probabilities and mutual information

Use this joint distribution of a binary outcome C and a weather variable T from the supplied information-theory handout:

SunnyRainySnowy
C = No0.300.200.10
C = Yes0.050.150.20
  1. Find P(C = Yes) and P(T = Rainy).
  2. Find the binary entropy H(C).
  3. Find H(C | T), then calculate IG(C; T).
Hint

Sum rows and columns for the marginal distributions. Use each weather column to calculate the conditional class probabilities, then take the weighted average.

Show solution

a) P(C = Yes) = 0.40; P(T = Rainy) = 0.35. b) H(C) ≈ 0.971 bits. c) H(C | T) ≈ 0.827 bits, so IG(C; T) ≈ 0.144 bits.

6. Stretch: can information gain ever be negative?

For discrete variables X and Y, reason about why conditioning on X cannot increase average entropy: H(Y | X) ≤ H(Y). What does this imply about IG(Y; X)?

Hint

Start with IG(Y; X) = H(Y) − H(Y | X). This is a property of average conditional entropy, not of every individual observation.

Show solution

Mutual information is non-negative for discrete distributions. Therefore H(Y) − H(Y | X) ≥ 0. A proof can be derived from the non-negativity of KL divergence; this result is more advanced than the earlier numerical exercises.

Connection to machine learning

Surprise measures information in a single observation. Entropy measures the average uncertainty of a distribution. Information gain measures how much one attribute reduces uncertainty about another; algorithms such as decision-tree learners can use this when selecting questions.
