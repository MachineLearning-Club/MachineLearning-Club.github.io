Homework (2p) — Probability and distributions

For every calculation, write the formula first, substitute the numerical values, and explain the final answer in one sentence. A calculator is permitted.

Formulas you may use

Equally likely outcomesP(A) = favourable outcomes ÷ possible outcomes
Two events togetherP(A ∩ B) = P(A) × P(B | A)
Independent eventsP(A ∩ B) = P(A) × P(B)
Conditional probabilityP(A | B) = P(A ∩ B) / P(B), when P(B) > 0
Weighted probabilityP(S) = P(S | R₁)P(R₁) + P(S | R₂)P(R₂) for two routes covering all cases
Expected numerical valueE[X] = Σ (possible value × its probability)

1. A ten-sided die

Roll a fair ten-sided die with faces numbered 1 to 10. Let X be the observed face.

  1. Find P(X = 4).
  2. Find P(X is even).
  3. Given the result is even, calculate P(X = 4 | X is even).
  4. Explain why the first and third probabilities differ.
Which formula should I use?

For (a) and (b), count favourable faces and divide by ten. For (c), the new possible outcomes are only {2, 4, 6, 8, 10}; alternatively use P(A | B) = P(A ∩ B) / P(B).

2. Two objects from a bag

A bag holds 3 red and 2 blue tokens. You draw two tokens in a row. Call the events R₁ (first token is red) and R₂ (second token is red).

  1. With replacement: put the first token back. Calculate P(R₁ ∩ R₂).
  2. Without replacement: keep the first token out. Calculate P(R₁ ∩ R₂).
  3. Explain which calculation involves independent draws and why the other second probability changes.
Use these steps
  1. Both cases: P(R₁) = 3/5.
  2. With replacement: P(R₂ | R₁) = 3/5 because the bag is restored to its original contents.
  3. Without replacement: P(R₂ | R₁) = 2/4 because only two red tokens remain among four.
  4. Multiply: P(R₁ ∩ R₂) = P(R₁) × P(R₂ | R₁).
Check the worked answer after solving

With replacement: (3/5) × (3/5) = 9/25 = 0.36. Without replacement: (3/5) × (2/4) = 3/10 = 0.30. The second draw depends on the first only when the first token is not returned.

3. Which probability distribution fits?

For each real-world situation, select the most appropriate introductory model. You do not need to calculate any distribution formula.

Quick reference — what does each model describe?
Bernoulli
One yes/no trial, such as success or failure.
Binomial
Number of successes in a fixed number of independent yes/no trials with the same success probability.
Discrete uniform
Each outcome in a finite set has the same probability.
Poisson
Count of events over a fixed interval, under a constant-rate and independence model.
Normal
Continuous measurements that are approximately bell-shaped around a mean.

Explore probability by moving a slider

Suppose a bag contains red and blue tokens. Move the slider to change the chance of choosing red. Observe what happens to the graph and to the weighted average of 0 and 1.

P(red) + P(blue) = 0.50 + 0.50 = 1.

Let X = 1 for red, 0 for blue. E[X] = 1×0.50 + 0×0.50 = 0.50.

Why must probabilities add to 1?

These two events are mutually exclusive and together cover every possible outcome. A probability cannot be negative or exceed 1, and the probability of the complete set of outcomes is exactly 1.

Weighted probability: which route arrives on time?

A delivery company uses Route A 70% of the time (90% on-time) and Route B 30% of the time (60% on-time). Find the total on-time chance.

Use: P(on time) = 0.70×0.90 + 0.30×0.60.

Show the weighted calculation

0.63 + 0.18 = 0.81, so the overall on-time probability is 81%. The weights 0.70 and 0.30 add to 1, and the result must be between 60% and 90%.

Optional challenge — Did the student know the answer?

A student has a 60% chance of knowing a true/false answer. Otherwise the student guesses, with a 50% chance of being correct. You observe a correct answer.

  1. Find P(correct) by combining the two possible routes: knew / guessed.
  2. Use Bayes' rule to find P(knew | correct).
  3. Explain why a correct response does not prove that the student knew the answer.

Formulas: P(C) = P(C|K)P(K) + P(C|G)P(G) and P(K|C) = P(C|K)P(K) / P(C).

Show the complete worked solution

P(C) = 1×0.60 + 0.50×0.40 = 0.80. Therefore P(K|C) = (1×0.60)/0.80 = 0.75, or 75%. A correct answer may also result from guessing.
