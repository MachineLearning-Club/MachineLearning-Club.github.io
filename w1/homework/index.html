Week 01 · Homework

What Is AI? Rules and Learning

Rules, search, learning from examples and language.

Real-life situation

A family's heating controller is still hard-coded to switch on below 19°C. A month of recorded preferences could make it more personal.

Mandatory (1p)

  1. Load the supplied sorting-data.csv instead of the six laboratory examples.
  2. Calculate new class prototypes using the existing code.
  3. Predict the classes in sorting-test.csv and report how many were correct.
  4. Show the two learned prototypes and at least one worked distance calculation.

Homework (2p)

  1. Add a test that detects an input far away from both prototypes; print a warning rather than claiming the answer is reliable.
  2. Make the classifier robust to an incomplete measurement (for example, missing reflectance) by rejecting the example with a clear explanation.
  3. Compare the first six-example model against the new model on the same test examples, and record which answers changed.
  4. Write a short explanation (approximately 100–150 words) of what the model learned and what it cannot infer about real materials.

Advanced — optional reading

Open the reasoning exercise sheet. The problems investigate whether successful predictions on known examples can establish a general rule. No additional software is required.

Submission

Submit one readable .ipynb file and a short README.md or text description with outputs, the number of correct predictions and the warning case. A GitHub account is not required in Week 1.
