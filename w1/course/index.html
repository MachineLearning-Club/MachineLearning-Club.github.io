1.1. Programs, rules and artificial intelligence

A computer takes input data, processes them using an algorithm, and produces output data. This basic structure remains useful even when the algorithm uses machine learning.

Input dataInformation supplied to the system
→
ProcessingInstructions or a model
→
Output dataThe resulting value or action

1.1.1. A rule you can control

Press the button. The light responds to the condition in the program; it does not need to learn anything.

INPUT DATA button_pressed = False
→
PROCESSING 
IF button_pressed THEN
    light ← ON
ELSE
    light ← OFF
ENDIF
→
OUTPUT DATA Light OFF
Definition

Rule-based system: a system that produces outputs using explicitly programmed conditions.

Definition

Machine learning: algorithms that learn patterns from data to make predictions or decisions.

Definition

Artificial intelligence (AI): the field of designing systems that perform tasks involving reasoning, planning, perception or learning.

Notes
  • Following a rule means applying a condition chosen by a programmer. The rule is unchanged by past use.
  • Searching for an answer means exploring possibilities, as in finding a route through a maze. Search is not necessarily learning.
  • Learning from data means building part of the decision-making process from examples. The resulting model still takes inputs and produces outputs.

  2. Describe one way a smart lamp could learn a person's preferred brightness instead of following a fixed button rule.
Show a possible solution

a) Input: whether the button is pressed. Processing: an IF condition. Output: ON or OFF. b) Collect examples of conditions and a person's chosen brightness, then train a model that predicts a preferred brightness for new conditions.

1.2. Learning from data

In machine learning, input data are often represented as a table of examples. Each column describes an attribute. Depending on the task, the algorithm may predict a label, form groups or choose actions.

1.2.1. Features and labels

Definition

Feature: a measurable property used as input to a model.

Definition

Label: the known answer attached to a supervised training example.

Observation

A feature might be an image pixel, temperature or word. A supervised label could be “cat”, “dog” or a known number.

1.2.2. Three families of machine learning

The central difference is the information available during learning. Compare the three diagrams before reading the definitions.

Supervised learning

Examples already have answers. Predict the label of a new example.

Unsupervised learning

No target labels are given. Discover similarities and groups.

Reinforcement learning

An agent acts, receives feedback, and improves its choices.

Definition

Supervised learning: learning from examples whose correct targets are provided.

Definition

Unsupervised learning: finding structure in data without supplied target labels.

Definition

Reinforcement learning: learning which actions to take from rewards and interaction with an environment.

Notes
  • Classification is supervised learning with a category as output.
  • Clustering is an unsupervised task that groups similar examples.
  • Playing to maximise a score can be formulated as a reinforcement learning task, but it can also be solved without learning, by searching a game tree.

1.3. Probability — reasoning under uncertainty

Before choosing a learning method, we need a way to describe what might happen and how likely each outcome is.

Definition

Probability: a number between 0 and 1 describing how likely an event is.

For equally likely outcomesP(event) = favourable outcomes ÷ all possible outcomes

1.3.1. Events and sample spaces

Roll two fair six-sided dice. There are 6 × 6 = 36 equally likely ordered results. The sum is 11 only in (5, 6) and (6, 5).

36 possible outcomes
Sum = 11 Possible after condition
PROBABILITY THAT THE SUM IS 11 2 / 36 = 1 / 18

Two favourable outcomes out of 36 possible outcomes.

1.3.2. Conditional probability

Definition

Conditional probability: the chance of A after learning that B happened, written P(A | B).

Knowing that the dice sum is prime leaves sums 2, 3, 5, 7 and 11. Exactly 15 of the 36 ordered outcomes qualify; two of those give 11.

Before new informationP(S = 11) = 2/36 = 1/18
Given that S is primeP(S = 11 | S prime) = 2/15
Observation

New evidence can change a probability because it changes the set of possible outcomes. This idea is central to probabilistic reasoning.

1.3.3. From evidence to beliefs: Bayes' rule

Suppose a student either knows the answer to a true/false question or guesses. Someone who guesses has a 50% chance of being correct. After a correct answer, how confident should we be that the student knew it?

Prior probabilityP(knows) = 0.60Assume 60% chance they knew it before hearing the answer.
→
Observed evidenceAnswer = correctKnowing gives 100% correctness; guessing gives 50%.
→
Updated probabilityP(knows | correct) = 0.75(1 × 0.60) / (1 × 0.60 + 0.5 × 0.40)
Definition

Bayes' rule: a way to update probabilities when new evidence becomes available.

Notes
  • Probabilities refer to events; model outputs can also be probabilities, scores or labels.
  • Do not confuse “more likely” with “certain”.

1.4. Information theory — measuring uncertainty

Probability tells us how likely something is. Information theory lets us measure how surprising an outcome is, and how much uncertainty disappears when we learn something new.

1.4.1. Surprise

Definition

Information content (surprise): I(x) = −log₂ P(x), measured in bits. A rarer event carries more information when observed.

Two dice sum to 21 / 36
−log₂(1/36) ≈ 5.170 bits
Two dice sum to 76 / 36
−log₂(6/36) ≈ 2.585 bits

1.4.2. Entropy

Definition

Entropy: the average amount of surprise in a probability distribution.

For two possible outcomes with probabilities p and 1 − p, entropy is H(p) = −p log₂ p − (1 − p) log₂(1 − p), with 0 log₂ 0 defined as 0.

AB
ENTROPY1.000 bits

A fair two-outcome process is maximally uncertain.

Observation

If an outcome is certain, entropy is 0 bits. If two outcomes are equally likely, entropy is 1 bit.

1.4.3. Information gain

Definition

Information gain: the decrease in entropy after receiving new information.

Uncertainty beforeH(sum of two dice) ≈ 3.274 bits
After seeing first die = 4H(sum | first die = 4) = log₂6 ≈ 2.585 bits
Information gained from observing the first die3.274 − 2.585 ≈ 0.690 bits

Information gain also helps select informative features in machine learning. That application is explored in later lessons.

1.5. A map of machine learning methods

Now that we have a language for data, probability, and information, we can recognise common AI approaches. This is a visual overview, not an implementation lesson.

TASK · IMAGES

Computer vision

Use images as input to identify, locate or describe objects.

Example: recognise a handwritten digit.
SUPERVISED · NUMBER

Linear regression

Fit a line to predict a numeric output from input measurements.

Example: predict a house's price.
MODEL · ONE NEURON

Perceptron

Combine weighted inputs and apply a threshold to make a binary decision.

Example: classify a simple pattern.
MODEL · MULTIPLE LAYERS

Neural network

Connect many simple computational units into layers that learn complex relationships.

Example: recognise objects in images.
SUPERVISED · ENSEMBLE

Random forest

Combine predictions from many decision trees.

Example: estimate whether a transaction is unusual.
UNSUPERVISED · GROUPS

Hierarchical clustering

Build a hierarchy of groups according to similarity.

Example: organise similar documents.
UNSUPERVISED · CENTRES

K-means clustering

Group nearby points around representative centres.

Example: segment products with similar characteristics.
GENERATIVE · CONTENT

Generative AI

Generate text, images, sounds or other content from learned patterns.

Example: draft a paragraph from a prompt.
Observation

Tasks (like computer vision) and model families (like neural networks) are different kinds of labels. A computer-vision system can use a neural network; a supervised problem can use a random forest or neural network.
