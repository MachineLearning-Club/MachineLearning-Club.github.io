1.1. Programs, rules and artificial intelligence

A computer takes input data, processes them using an algorithm, and produces output data. This basic structure remains useful even when the algorithm uses machine learning.

Input dataInformation supplied to the system
→
ProcessingInstructions or a model
→
Output dataThe resulting value or action

1.1.1. A rule you can control

Press the button. The light responds to the condition in the program; it does not need to learn anything.

INPUT DATA button_pressed = False
→
PROCESSING 
IF button_pressed THEN
    light ← ON
ELSE
    light ← OFF
ENDIF
→
OUTPUT DATA Light OFF
Definition

Rule-based system: a system that produces outputs using explicitly programmed conditions.

Definition

Machine learning: algorithms that learn patterns from data to make predictions or decisions.

Definition

Artificial intelligence (AI): the field of designing systems that perform tasks involving reasoning, planning, perception or learning.

Notes
  • Following a rule means applying a condition chosen by a programmer. The rule is unchanged by past use.
  • Searching for an answer means exploring possibilities, as in finding a route through a maze. Search is not necessarily learning.
  • Learning from data means building part of the decision-making process from examples. The resulting model still takes inputs and produces outputs.

1.3. The machine learning methods map

Some terms name a learning setup; others name a task, a model or an application area. Use the three families above as a map for the methods below. Select any diagram to follow one example of how it operates.

1.3.1. Supervised — learn from known targets

Input: examples paired with answers (x, y). Goal: predict ŷ for a new input. Classification outputs categories; regression outputs numbers.

SUPERVISED · NUMBER

Linear regression

New input follows the learned line to a numerical prediction.

Fit a line to predict a numeric output from input measurements.

Example: predict a house's price.
MODEL · ONE NEURON

Perceptron

Input values are weighted and combined, then a threshold produces a decision.

Combine weighted inputs and apply a threshold to make a binary decision.

Example: classify a simple pattern.
MODEL · MULTIPLE LAYERS

Neural network

Information flows through several layers of connected computational units.

Connect many simple computational units into layers that learn complex relationships.

Example: recognise objects in images.
SUPERVISED · ENSEMBLE

Random forest

Several decision trees each vote; their combined votes determine the answer.

Combine predictions from many decision trees.

Example: estimate whether a transaction is unusual.

1.3.2. Unsupervised — discover structure

Input: examples x without known answers. Goal: discover useful patterns such as flat groups or nested groups. No target label tells the algorithm how to classify each input.

UNSUPERVISED · CENTRES

K-means clustering

Points are assigned to their nearest centre; the centre then moves to their average.

Group nearby points around representative centres.

Example: segment products with similar characteristics.
UNSUPERVISED · GROUPS

Hierarchical clustering

Pairs of similar items merge into larger groups in a tree-like hierarchy.

Build a hierarchy of groups according to similarity.

Example: organise similar documents.

1.3.3. Reinforcement — improve actions using rewards

Input: observations of the environment and reward feedback. Goal: learn a policy π(state) → action that earns high long-term reward, rather than predicting a provided target label.

AGENT · REWARD

Reinforcement learning

The agent chooses an action, receives a reward and next state, then improves its policy.

Learn which actions bring the greatest future reward by interacting with an environment.

Example: a simulated robot learning to reach a goal.

1.3.4. Application areas — what AI is used for

Computer vision describes working with images, while generative AI describes creating new content. These are not alternatives to supervised, unsupervised or reinforcement learning: an application can combine several approaches.

TASK · IMAGES

Computer vision

An image enters a recogniser, which identifies a category or location.

Use images as input to identify, locate or describe objects.

Example: recognise a handwritten digit.
GENERATIVE · CONTENT

Generative AI

A prompt guides a model to produce a new output such as a paragraph.

Generate text, images, sounds or other content from learned patterns.

Example: draft a paragraph from a prompt.
One application can combine several ideas.

A camera identifies an object (computer vision) using a trained neural network (model). If it predicts a known category, the training task is supervised classification. These labels describe different aspects of the same system.

1.4. Probability — from counting to evidence

A probability describes how likely an event is. We start by counting equally likely outcomes, then learn what changes after receiving more information.

1.4.1. Events and the sample space

Definition

Sample space Ω: the set of all possible outcomes of an experiment.

Definition

Event A⊆Ω: the collection of outcomes satisfying a particular condition.

For equally likely outcomes P(A)=# favourable outcomes# all possible outcomes=|A||Ω| A fair ten-sided die: Ω = {1, 2, 3, …, 10} and |Ω| = 10.

Choose a face on a fair ten-sided die. The experiment has ten equally likely results. Then reveal that the die showed an even number: what changes?

One favourable outcome among ten equally likely outcomes.

1.4.2. Conditional probability

Before receiving new information, we count within all of Ω. After learning that event B occurred, outcomes outside B are ruled out. We keep only the possibilities in B and count favourable results within them.

Original sample spaceP(A)=|A||Ω|
→
Reduced sample space: BP(A|B)=|A∩B||B|
Definition

Conditional probability: the probability of A when B is known to have happened. In general, for P(B)>0:

P(A|B)=P(A∩B)P(B)

Example: guess the number 4. Before learning anything, P(4) = 1/10. After learning that the result was even, exactly five faces remain possible (2, 4, 6, 8, 10). Now P(4 | even) = 1/5. Guessing an odd face would instead have probability 0.

1.4.3. Deriving Bayes' theorem

Write the definition of conditional probability in both directions. Both expressions contain the same joint probability P(A∩B).

Condition on BP(A|B)=P(A∩B)P(B)
Condition on AP(B|A)=P(A∩B)P(A)
Rearrange and equateP(A|B)P(B)=P(B|A)P(A)
Bayes' theoremP(A|B)=P(B|A)P(A)P(B)

Bayes' theorem lets us update a belief about A after observing B. The denominator P(B) includes all ways the evidence B could occur.

1.5. Probability distributions and expected value

A single probability describes one event. A probability distribution describes every possible value of a random variable and how likely each value is.

1.5.1. From outcomes to distributions

Definition

Random variable: a numerical value determined by a random experiment. For a ten-sided die, let X∈{1,2,…,10} be the rolled face.

Discrete — probability mass function (PMF)

Each possible value gets a probability p(x)=P(X=x). Bar heights sum to 1.

Examples: dice faces, number of successes, number of visitors.
Continuous — probability density function (PDF)

Probabilities correspond to areas under the curve over intervals, not to the height at one point.

Examples: continuous lengths or temperatures.
Definition

Expected value: the probability-weighted average of a random variable. For a discrete random variable:

E[X]=∑x∈values of Xx·P(X=x)

Observation

The fair and tricky dice have the same expected value, 5.50, but clearly different probabilities. Matching an average does not establish that a die is fair. The frequency of individual faces and the amount of variation also matter.

Notes
  • For 30 independent rolls, the expected sum is 30×E[X].
  • A mathematical expectation describes what we anticipate on average across repeated experiments; it is not a promise about one sample.
  • The three ten-sided distributions are teaching adaptations. The source problem describes a six-sided die with different probabilities.
