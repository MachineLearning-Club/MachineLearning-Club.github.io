Week 01 · Course

What Is AI? Rules and Learning

How can a computer make a decision, and what changes when it learns from examples instead of following a fixed rule?

Essential question

A programmer can specify a rule directly. A learning algorithm instead calculates a model from observed data. In this lesson, you will follow both approaches from input to output.

Start readingTry the modelContinue to the laboratory
Teacher Guide Course overview and teaching sequence

Course summary

Start from input data → processing → output data, using an interactive button-controlled lamp. Compare supervised, unsupervised and reinforcement learning visually. Separate training, inference and testing, then study a complete supervised decision tree for tic-tac-toe and a one-iteration K-means clustering demonstration.

By the end: identify input, processing and output; distinguish the three learning families by their feedback; identify training, inference and testing; explain how optimal game-tree search can generate supervised labels; understand one K-means iteration; design a fair evaluation.

1.1. Programs, rules and artificial intelligence

A computer takes input data, processes them using an algorithm, and produces output data. This basic structure remains useful even when the algorithm uses machine learning.

Input dataInformation supplied to the system
→
ProcessingInstructions or a model
→
Output dataThe resulting value or action

1.1.1. A rule you can control

Press the button. The light responds to the condition in the program; it does not need to learn anything.

INPUT DATA button_pressed = False
→
PROCESSING 
IF button_pressed THEN
    light ← ON
ELSE
    light ← OFF
ENDIF
→
OUTPUT DATA Light OFF
Definition

Rule-based system: a system that produces outputs using explicitly programmed conditions.

Definition

Machine learning: algorithms that learn patterns from data to make predictions or decisions.

Definition

Artificial intelligence (AI): the field of designing systems that perform tasks involving reasoning, planning, perception or learning.

Observation

Not all automated systems use machine learning, and not every AI system is a neural network.

Notes
  • Following a rule means applying a condition chosen by a programmer. The rule is unchanged by past use.
  • Searching for an answer means exploring possibilities, as in finding a route through a maze. Search is not necessarily learning.
  • Learning from data means building part of the decision-making process from examples. The resulting model still takes inputs and produces outputs.
Exercise 1
1)
  1. Identify the input, processing rule and output of the lightbulb program.
  2. Describe one way a smart lamp could learn a person's preferred brightness instead of following a fixed button rule.
Show a possible solution

a) Input: whether the button is pressed. Processing: an IF condition. Output: ON or OFF. b) Collect examples of conditions and a person's chosen brightness, then train a model that predicts a preferred brightness for new conditions.

1.2.2. Three families of machine learning

The central difference is the information available during learning. Compare the three diagrams before reading the definitions.

Supervised learning

Examples already have answers. Predict the label of a new example.

Unsupervised learning

No target labels are given. Discover similarities and groups.

Reinforcement learning

An agent acts, receives feedback, and improves its choices.

Definition

Supervised learning: learning from examples whose correct targets are provided.

Definition

Unsupervised learning: finding structure in data without supplied target labels.

Definition

Reinforcement learning: learning which actions to take from rewards and interaction with an environment.

Observation

Labels, groups and rewards are not interchangeable. The methods address different learning problems, although real systems may combine them.

Notes
  • Classification is supervised learning with a category as output.
  • Clustering is an unsupervised task that groups similar examples.
  • Playing to maximise a score can be formulated as a reinforcement learning task, but it can also be solved without learning, by searching a game tree.

  2. The same measurements have no fruit names. You want to group similar fruits. Which family is suitable, and why?
  3. A game agent receives points after its actions. Which family uses this feedback to improve decisions?
Show a possible solution

a) Supervised learning, predicting fruit labels. b) Unsupervised learning, because the algorithm receives no target categories. c) Reinforcement learning, because actions are evaluated through rewards.

1.3. Training, prediction and testing

The same model is used in different ways at different stages. Look at what enters and leaves each process.

01

Training

Examples + known answers→Learning algorithm→Trained model

The algorithm determines the model's parameters from examples.

02

Prediction (inference)

New input + trained model→Predicted output

Use the model on a new example. Its parameters do not change merely because it makes a prediction.

03

Testing

Prediction + known test answer→Correct / incorrect

Compare predictions with examples that were not used to train the model.

Definition

Training: using examples to determine a model's parameters.

Definition

Inference: applying a trained model to obtain a prediction.

Definition

Testing: evaluating predictions on separate examples with known correct answers.

Observation

A model can be correct on every training example and still fail on unfamiliar inputs. Training accuracy alone does not demonstrate generalisation.

Notes
  • For a fair test, the answers in the test set must not influence how the model is trained.
  • During inference, the input is new but the trained model can stay unchanged.

a) To test whether the model handles unseen examples instead of memorising training examples. b) Record predictions and errors for a separate, varied labelled test set.

Observation

Where the supervision comes from matters: minimax is search, not learning. Here it generates optimal labels, and the decision tree memorises the complete mapping from board attributes to those labels. Complete coverage and verification make the tree unbeatable; a small tree trained on only a few games would not have that guarantee.

Notes
  • This is a categorical decision tree built by exhaustive lookup, rather than a compact ID3 tree. Week 2 introduces how a smaller tree is learned from examples.
  • It plays perfectly only for the ordinary 3 × 3 game with X moving first and legal alternating turns.

1.5. Does the model actually work?

A demonstration tells us what happened on a few inputs. Testing tells us how reliably a model behaves on new inputs.

✓

Training examples

The model may recognise examples it has already seen.

This does not prove generalisation.
?

New test examples

Use unfamiliar inputs with independently known correct answers.

Record successes and failures.
Definition

Generalisation: performing well on relevant examples not used in training.

Observation

A confidence score is not proof that a prediction is correct. Its meaning depends on the model and how that score was produced.

Notes
  • Check whether the training and test data represent the situations where the model will be used.
  • Inspect failures, not only successful demonstrations.
  • For classroom activities, use ordinary objects or synthetic data rather than classmates' faces, voices or private information.
Exercise 5
1)
  1. A model gets every training example right. Design a fair test to check whether it has actually learned something useful.
  2. The model makes mistakes on some new examples. State two questions you should investigate before improving it.
Show a possible solution

a) Keep a separate set of varied examples whose labels were not used during training and compare every prediction to its correct answer. b) Are the training examples representative? Do errors occur for particular features, conditions or categories?
