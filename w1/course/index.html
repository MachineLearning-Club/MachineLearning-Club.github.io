Start with a useful question: what task is a system doing, and what makes it produce its answer?

By the end, you can…

You do not need a perfect one-sentence definition. You need a way to inspect a system carefully.

  • Describe AI as a broad area of computing, not one single technique.
  • Explain that machine learning is one part of AI, not a synonym for it.
  • Use a problem’s output and available evidence to suggest an approach.
  • Explain training labels, predictions and what confidence does not guarantee.
02

AI is a field, not a magic box

Artificial intelligence is an area of computing concerned with systems that perform tasks often associated with intelligent behaviour: recognizing patterns, processing language, making predictions, choosing actions, or planning.

Our working question: What task does the system perform, and how is its behaviour produced? The answer might involve rules, search, learned patterns, or a combination.
A useful clue

Look at the job

Recognising a face, suggesting a route, and drafting text are different tasks. They call for different methods and different checks.

A useful caution

Do not judge by appearance

A product can have a polished interface without using AI. A system can use AI without looking human or “thinking” like a person.

03

A map of related ideas

These labels are related, but they do not all mean the same thing.

Artificial intelligence (AI) A broad area that includes rule-based reasoning, search and planning, and machine learning.
Machine learning (ML) Methods that fit patterns from data so a system can make predictions or decisions.
Deep learning Machine learning that uses neural networks with many layers.
Where generative AI fits

It describes what a system produces

Generative AI creates new content such as text, images, audio, or code. Many familiar generative tools use deep learning. “Generative” describes the kind of output, so it overlaps with the map above rather than adding a strict extra rung.

Remember: machine learning is part of AI; deep learning is part of machine learning. Not every AI system learns from data, and not every automated program is AI. Rule-based reasoning can be AI; a simple timer or light threshold alone is ordinary automation.
04

Same world, different methods

Fixed rule

“If the room is dark, switch on the lamp.”

The rule is written in advance. A sensor supplies a value, but the example does not show a system learning from examples.

Learned pattern

“Does this email look like spam?”

A classifier can learn from emails labelled “spam” or “not spam”. It can still make mistakes, especially on unfamiliar cases.

Search and planning

“Which route meets these constraints?”

A planner can compare possible routes using distance, closures, and deadlines. Route choice can use search even when it has not learned a route from examples.

Generated output

“Draft a summary from these notes.”

A generative model can produce fluent text, but fluent wording is not proof that every detail is accurate. A person should check it.

05

Approach clues for the lab

Ask what kind of answer the problem needs. That often narrows the options.

A toolkit, not seven separate boxes. These names describe different aspects of a system. Classification and regression are prediction tasks; clustering finds groups; reinforcement learning describes learning through action and reward; generative AI describes creating content. A product can combine them.
R

Rules and automation

Follow an explicitly programmed condition or sequence.

C

Classification

Choose a category using examples with known labels.

#

Regression

Estimate a number, such as energy use or journey time.

G

Clustering

Group similar items when no group labels are supplied.

P

Search and planning

Find a useful sequence of actions under constraints.

↗

Reinforcement learning

Learn actions through feedback or rewards from an environment.

Aa

Generative AI

Create a new draft, image, audio clip, or other content.

Three ways to learn: supervised learning uses examples with known target answers (such as a category or a measured number); unsupervised learning looks for structure without supplied target labels; reinforcement learning uses actions and reward feedback. Classification and regression are common supervised tasks; clustering is a common unsupervised task.

Worked examples · follow the evidence

Classification: 500 emails are already labelled spam or not spam. A new email goes in; a category comes out. The labels provide training answers. A genuine school email could be wrongly blocked.

Regression: past days have a temperature and the number of ice creams sold. Tomorrow’s temperature goes in; an estimated number of sales comes out. A rainy day or school closure could make the estimate unreliable. A number used as a category code, such as postcode, is not a regression target just because it contains digits.

Clustering: group unlabelled books using similarities in their descriptions. The groups are discovered, not supplied as correct answers. A person must inspect and name them; the groups need not match school subjects.

Planning versus reinforcement learning: comparing moves on a known maze map is search/planning. A simulated agent that improves its action choices over repeated trials using reward feedback is reinforcement learning. Merely trying many routes does not establish learning.

Training versus use: fitting a spam model from labelled emails is training. Applying that model to a new email is prediction (also called inference). Predicting does not automatically retrain the model.

Real products can combine approaches. In today’s lab, choose the main approach suggested by the information in the scenario, then explain your clue.
