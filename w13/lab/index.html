Week 13 · Laboratory

FIICode: Baselines and Metrics

Turn a competition task into reproducible measurable experiments.

24 Mar 2027One weekly session · 60 minutes
CourseLaboratoryHomeworkAdvanced

Laboratory learning objectives

  1. Inspect a dataset
  2. Train a first baseline
  3. Record a reproducible score

Guided laboratory tasks

  1. Use the official challenge when available or a practice dataset
  2. Create a data dictionary and evaluation strategy
  3. Fit a baseline and save parameters and score

Work using PRIMM: Predict, Run, Investigate, Modify, Make. Starter code and AI assistance are allowed if you can explain the result.

Evidence to keep

A concise worked calculation, a code/notebook result, and a written explanation of one error or limitation.
