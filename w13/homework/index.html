Week 13 · Homework

FiiCode II: Build a Working Application

Teacher Guide One 60-minute session; core + optional Research

Learning outcome

Explain the processing pipeline; trace one k-NN prediction; connect model output to a UI.

Teaching sequence

0–12 draw the pipeline; 12–27 trace distance and votes; 27–45 use the interactive app; 45–55 test invalid inputs; 55–60 identify a limitation.

Core: reproducible observations, one experiment and an explanation in ordinary language. Research (3p): additional mathematics, model investigation or application engineering. All features and labels in this project are synthetic; do not infer student traits or real room conditions.

Independent preparation project: these are deliberately simulated examples for practising data analysis and software engineering. They are not official FiiCode rules, datasets, judging criteria or submissions.

The same study-space dataset, baseline and application are used in every homework from Week 12 to Week 15. Submit evidence, not just a final number.

Project starter ZIPProblem and file layout

Mandatory — trace a prediction (1p)

Use the fixed training data and the input (occupancy=35, noise=42, wifi=4, outlets=1, minutes=60). In prediction_examples.csv record the input, k=3 predicted class and the three nearest neighbour IDs and labels.

Acceptance: actual neighbours from the supplied data and the published weighted squared distance; no hardcoded output-only function.

Homework — working application and tests (2p)

Write or adapt model.py to expose predict(sample, k). Show two contrasting room profiles and test one invalid input, such as Wi-Fi 8. Add app_evidence.md with a screenshot or precise reproduction steps for the browser interface.

Required behaviour: predictions from training examples, deterministic tie handling, readable error for invalid input and an output label in avoid/consider/good.

Research — accessibility improvement (3p, optional)

Add one keyboard-accessible interaction or clearer numerical explanation to the application. Supply one test case and explain why the change improves usability without altering classifier mathematics.

Delivery contract

Produce the named files, record original and modified results, and export them through the corresponding Laboratory submission panel. The named ZIP is prepared locally; teacher collection is a separate step.
