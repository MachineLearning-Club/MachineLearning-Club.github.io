Week 10 · Laboratory

Integrated AI Systems I

Combine vision, prediction, decision rules and user feedback.

3 Mar 2027One weekly session · 60 minutes
CourseLaboratoryHomeworkAdvanced

Laboratory learning objectives

  1. Assemble image-to-action components
  2. Log intermediate predictions
  3. Test novel inputs

Guided laboratory tasks

  1. Join an image classifier to a recommendation rule
  2. Log intermediate model outputs and decisions
  3. Test blurry or unknown inputs with a human-review fallback

Work using PRIMM: Predict, Run, Investigate, Modify, Make. Starter code and AI assistance are allowed if you can explain the result.

Evidence to keep

A concise worked calculation, a code/notebook result, and a written explanation of one error or limitation.
