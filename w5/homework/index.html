Week 05 · Homework

Computer Vision: Images as Data

From pixels and channels to simple visual transformations.

Real-life situation

A teacher wants to improve a photograph of homework so it is easier to read.

Mandatory (1p)

Apply a threshold to five pixel values.

Suggested starting steps
  1. Open the Week 5 Laboratory and run the prepared code.
  2. Identify the relevant input and output.
  3. Change the smallest amount of code needed to solve the situation.

Homework (2p)

Modify the supplied image-preprocessing notebook and show side-by-side images.

What to submit

Use the laboratory submission area to prepare a named notebook or Python file. Add one screenshot, output table or short explanation of what changed.
