Week 05 · Laboratory

K-Nearest Neighbours

Measure similarity and classify by voting among neighbours.

20 Jan 2027One weekly session · 60 minutes
CourseLaboratoryHomeworkAdvanced

Laboratory learning objectives

  1. Locate nearest neighbours
  2. Compare K=1 and K=3 predictions
  3. Run a scikit-learn KNN notebook

Guided laboratory tasks

  1. Plot labelled points and calculate three nearest distances
  2. Predict classes with K=1 and K=3
  3. Compare unscaled and standardised features in Python

Work using PRIMM: Predict, Run, Investigate, Modify, Make. Starter code and AI assistance are allowed if you can explain the result.

Evidence to keep

A concise worked calculation, a code/notebook result, and a written explanation of one error or limitation.
