Week 05 · Laboratory

Computer Vision: Images as Data

From pixels and channels to simple visual transformations.

Lab challenge

Clean a fictional low-contrast worksheet photographed on a phone.

1. Open an interactive experiment

Launch Image Kernels interactive

Observe the example first. Predict one change before adjusting any parameter.

2. Run the guided Python experiment

  1. Experiment with a tiny grayscale pixel grid.
  2. Use an interactive filter to compare blur and edges.
  3. Run the image notebook to convert pixels to black and white.
  4. Explain which filter preserves the handwriting best.

Research (3p) (optional)

Implement a custom 3×3 edge kernel on a tiny matrix and show the result.

How to approach this investigation
  1. Start from the working lab code.
  2. Change one thing and keep a record of the original result.
  3. Explain what the new result shows and where it might be misleading.
