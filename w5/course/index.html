1. The picture is a grid of numbers

Real-life question. A photograph looks like a continuous image on screen.

A digital image is a rectangular grid of pixels. Grayscale pixels often range from 0 (black) to 255 (white).

Worked example.

A 3×3 image is a table of nine intensity values; changing its centre affects one small square.

image = [[0,0,255],[0,255,0],[255,0,0]]
print(image[1][1])

2. Colours, channels and dimensions

Real-life question. A red pixel is not described by one intensity value.

RGB images store three channel values per pixel. A shape such as 64×64×3 records height, width and channels.

Worked example.

Pure red may be represented as (255,0,0); black is (0,0,0).

rgb = (255, 0, 0)
print('Red channel:',rgb[0])

3. Thresholding and simple filters

Real-life question. Ink is dark and paper is bright in a scan.

Thresholding converts each value into light or dark. A small blur or edge-detection filter examines neighbouring pixels.

Worked example.

With threshold 128, intensity 80 → black; 230 → white.

pixels = [80,140,230]
print([0 if p<128 else 255 for p in pixels])
