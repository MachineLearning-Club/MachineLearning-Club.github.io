5.1. A picture can be represented by numbers

Core idea

Image = organised pixel values. The computer does not receive “the word hello”; it receives an array of intensities or colour channels. Image processing changes numbers, and visual interpretation comes from the arrangement.

Imagine a photographed worksheet with dark writing, bright paper and uneven illumination. Before trying to recognise characters, we may improve the image so the foreground stands out. This week teaches the arithmetic behind the transformation, not a full optical character recognition model.

Think of a grayscale image as a two-dimensional table I[row][column]. Each cell is one pixel. In our eight-bit examples, 0 is black and 255 is white, with shades of grey between them.

Predict

If a photograph is 6 pixels across and 4 pixels high, how many grayscale intensity numbers does it contain? How many if every pixel has three RGB channels?

Answer

Grayscale: 6×4=24 values; RGB: 6×4×3=72 channel values, assuming 8 bits per channel and no metadata.

5.2. Draw a number grid and change one pixel

Our worksheet is a tiny 5×5 image: the background is light, while some pixel intensities are small because they represent pencil marks. Click a square below to change its intensity, then inspect the number and the visual result.

Pixel indices usually start at zero in Python: the top-left cell is I[0][0]. Increasing a cell from 40 to 220 makes it much lighter. In a larger image, a single altered pixel can create visible noise.

Why use rows before columns?

A Python list of lists is indexed as I[row][column]. The row increases down the image; the column increases to the right. This is an array convention, not Cartesian x/y notation.

5.3. How do colours become grayscale numbers?

One colour pixel can contain three values (R,G,B) from 0 to 255. For example (120,180,240) contains more blue than red. To produce one grayscale number, different conversion rules are possible.

Worked example — one RGB pixel

  1. Simple channel mean: (120+180+240)/3 = 180.
  2. Weighted luminance-style grayscale: 0.2126×120 + 0.7152×180 + 0.0722×240 = 171.576 ≈ 172.
  3. Alternative desaturation: (min(R,G,B)+max(R,G,B))/2 = (120+240)/2 = 180.
  4. Different choices can produce different numbers because they measure “brightness” differently. For school exercises we state the rule explicitly.

Change the channels and compare conversions

Does grayscale mean the same thing as converting to black or white?

No. Grayscale typically allows many values between 0 and 255. A binary black/white image uses only two output levels, commonly 0 and 255; thresholding is one way to obtain it.

5.4. Remove background using a threshold

Core idea

Compare each pixel with a boundary. For threshold T, assign 0 (black) when intensity is below T and 255 (white) when it is at least T.

Fully worked threshold

For inputs [30, 100, 127, 128, 220, 250] and T = 128:

30 < 128 → 0; 100 < 128 → 0; 127 < 128 → 0; 128 ≥ 128 → 255; 220 → 255; 250 → 255.

Output: [0, 0, 0, 255, 255, 255].

FOR each row in image:
    FOR each pixel in row:
        IF pixel < threshold:
            output_pixel = 0
        ELSE:
            output_pixel = 255

Move the threshold in the interactive grid above and watch letters or faint marks disappear. A single global threshold may fail on an unevenly lit page: some dark paper shadows can be confused with writing.

Practice — what changes if the threshold is 200?

Values less than 200 become black, including 128. Only 220 and 250 remain white in the six-value example. That may turn too much of a light-grey background into black.

5.5. A filter uses the neighbouring pixels

Thresholding looks at one pixel alone. A spatial filter looks at a local neighbourhood. A 3×3 average filter replaces the centre with the mean of the nine nearby values, which tends to smooth abrupt differences.

Compute one 3×3 mean by hand

000
0255255
0255255
  1. There are four values equal to 255 and five equal to 0.
  2. Sum = 4×255=1020.
  3. Average = 1020/9≈113.3, so the centre can become 113 after rounding.
  4. Edges become smoother, but fine handwriting can also become blurry.

A kernel gives each neighbouring pixel a weight. The average kernel has nine weights of 1/9. A sharpening or edge kernel may use negative and positive weights; intermediate results can fall outside 0–255, so clipping rules are necessary.

Advanced preview — a sharpening kernel from the Vision laboratory

The uploaded Vision Lab 1 includes the matrix [[0,-2,0],[-2,8,-2],[0,-2,0]]. Multiply each of the nine input pixels by the matching kernel entry and sum the products. This is a detail-enhancement response, not a normalised blur. A large result may require clipping or other display scaling.

5.6. Is the processed worksheet actually better?

Not every cleaner-looking image is more useful. Thresholding may erase pale pencil strokes. Blurring can reduce noise but also remove thin lines. A fair evaluation needs a purpose: can a reader or recogniser distinguish the intended characters?

OperationPotential benefitPotential loss
GrayscaleOne number per pixel is easier to processColour distinctions disappear
ThresholdStrong separation of foreground/backgroundFaint writing disappears
3×3 meanReduces local isolated variationsThin edges become blurred
SharpenHighlights local transitionsNoise may be amplified

This connects to the Week 4 revision: a numerical transformation must be checked using examples it was not tuned to. Image-processing quality is a separate question from classifier accuracy.
