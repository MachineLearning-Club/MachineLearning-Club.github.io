1. The picture is a grid of numbers

1.1. Real-life situation

A photograph looks like a continuous image on screen.

1.2. Understanding the concept

A digital image is a rectangular grid of pixels. Grayscale pixels often range from 0 (black) to 255 (white).

1.3. Worked example

A 3×3 image is a table of nine intensity values; changing its centre affects one small square.

1.4. Try it in Python

image = [[0,0,255],[0,255,0],[255,0,0]]
print(image[1][1])
See the algorithm step by step

  2. Change one number
  3. Observe the displayed square

2. Colours, channels and dimensions

2.1. Real-life situation

A red pixel is not described by one intensity value.

2.2. Understanding the concept

RGB images store three channel values per pixel. A shape such as 64×64×3 records height, width and channels.

2.3. Worked example

Pure red may be represented as (255,0,0); black is (0,0,0).

2.4. Try it in Python

rgb = (255, 0, 0)
print('Red channel:',rgb[0])
See the algorithm step by step
  1. Read one RGB tuple
  2. Change one channel
  3. Predict the colour

3. Thresholding and simple filters

3.1. Real-life situation

Ink is dark and paper is bright in a scan.

3.2. Understanding the concept

Thresholding converts each value into light or dark. A small blur or edge-detection filter examines neighbouring pixels.

3.3. Worked example

With threshold 128, intensity 80 → black; 230 → white.

3.4. Try it in Python

pixels = [80,140,230]
print([0 if p<128 else 255 for p in pixels])
See the algorithm step by step
  1. Choose a threshold
  2. Apply it to each pixel
  3. Compare before and after

4. Seeing what changes

4.1. Real-life situation

A scan becomes hard to read after over-aggressive filtering.

4.2. Understanding the concept

Preprocessing must preserve useful information. A clean result is not always one that looks more dramatic.

4.3. Worked example

A threshold of 250 may erase grey pencil strokes that were present at 180.

4.4. Try it in Python

print('Always keep the original image for comparison')

  2. Inspect missing details
