Week 05 · Advanced

Computer Vision: Images as Data

Numerical image-processing reasoning

These five optional problems build directly from the uploaded Vision Lab 1 and Lab 2 exercises. All example images are small synthetic matrices, so solutions can be verified on paper before using Python.

Useful conventions

grayscale = 0.2126R + 0.7152G + 0.0722B; threshold outputs 0 for input < T and 255 otherwise; 3×3 average is the sum of the nine pixel values divided by 9.

Five worked challenges

1. Grayscale formulas need not agree

Convert pure red (255,0,0) and pure green (0,255,0) using a simple three-channel mean and the weighted grayscale formula.

Solution

Both simple means are 85. With weights 0.2126, 0.7152, 0.0722, red gives 54.213 and green gives 182.376. The weighted formula captures a stronger contribution from the green channel.

2. Calculate a sharpening response

For patch [[0,0,0],[0,255,255],[0,255,255]] and kernel [[0,−2,0],[−2,8,−2],[0,−2,0]], multiply corresponding entries and sum. State what clipping to [0,255] does.

Solution

Centre contributes 8×255=2040; right and bottom neighbours contribute −2×255 each, the other cross neighbours contribute 0. Total is 2040−510−510=1020. If clipped to 8-bit grayscale, output becomes 255. Unclipped response and displayed value are different.

3. What happens at the edge of a 3×3 image?

A 3×3 filter applied to the top-left pixel needs neighbours outside the image. Compare zero padding with the method of replicating the nearest border pixel for a solid-white image.

Solution

For a 3×3 mean of an all-255 image at the top-left corner, zero padding gives 4×255/9≈113.3; edge replication keeps all nine sampled values at 255, giving 255. Padding is part of the algorithm definition and changes the output.

4. When can thresholding erase useful marks?

A faint stroke has intensities [145,160,174] and the page background is 220. Apply thresholds 128, 180 and 230. Which threshold separates strokes from background, assuming lower intensity means darker?

Solution

T=128 gives everything white, losing the strokes. T=180 makes all three stroke pixels black and background white. T=230 makes both strokes and background black. For these invented values, T=180 works; other photographs might need different thresholds.

5. Mean filtering and noise

A 3×3 neighbourhood is all 200 except its centre, which is 0. Calculate the output of a 3×3 mean filter at the centre and compare with the original.

Solution

Mean=(8×200+0)/9≈177.78, suppressing the isolated dark dot. However, if the dot were intentional punctuation, the same operation would destroy useful information. Smoothing is a trade-off.
