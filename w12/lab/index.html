Week 12 · Laboratory

Language Models and Trust

LLMs, hallucinations, verification, model cards and project scoping.

17 Mar 2027One weekly session · 60 minutes
CourseLaboratoryHomeworkAdvanced

Laboratory learning objectives

  1. Compare two prompts
  2. Fact-check generated claims
  3. Define a project goal and metric

Guided laboratory tasks

  1. Try a vague prompt and a structured prompt
  2. Verify two factual model claims with trusted references
  3. Draft target data baseline and metric for a project

Work using PRIMM: Predict, Run, Investigate, Modify, Make. Starter code and AI assistance are allowed if you can explain the result.

Evidence to keep

A concise worked calculation, a code/notebook result, and a written explanation of one error or limitation.
