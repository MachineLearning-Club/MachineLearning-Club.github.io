Week 12 · Lab

FiiCode I: Read the Challenge and Establish a Baseline

Teacher Guide One 60-minute session; core + optional Research

Learning outcome

Define the prediction problem; audit 240 synthetic examples; establish a 15/45 baseline.

Teaching sequence

0–10 introduce the use case; 10–23 identify five features and labels; 23–39 inspect CSV; 39–51 measure the baseline; 51–60 discuss leakage.

Core: reproducible observations, one experiment and an explanation in ordinary language. Research (3p): additional mathematics, model investigation or application engineering. All features and labels in this project are synthetic; do not infer student traits or real room conditions.

Contents
  • 1. Open and inspect the dataset
  • 2. Run a true baseline
  • 3. Preview what the classifier will become
  • Submission

Independent preparation project: these are deliberately simulated examples for practising data analysis and software engineering. They are not official FiiCode rules, datasets, judging criteria or submissions.

1. Open and inspect the dataset

Download train.csv and validation.csv. The first line is the column header. Every record contains an ID, five features and the expected class. Count examples for each class and confirm that there are no duplicate IDs.

  1. Predict how many examples of each label exist in the training split.
  2. Count them in Python, not by hand.
  3. Check that each feature contains a valid numerical value.
  4. Explain why this artificial sample does not measure real students' preferences.

Expected auditable quantities

150 training rows, 45 validation rows, 50 training examples per label, and 15 validation examples per label. A row ID identifies an artificial example, not a student.

2. Run a true baseline

Open the prepared notebook and execute the most-frequent-label classifier. It must choose its constant label using training labels only. Afterwards, evaluate on validation examples and record the numerator.

Expected reference result: the baseline predicts avoid and correctly labels 15/45 validation records. Try to explain this result before reading the notebook's output.

3. Preview what the classifier will become

The same dataset powers this web experiment for the next three weeks. Use it to compare a quiet room and a crowded noisy room. Do not treat a predicted synthetic label as a real recommendation.
