FIICode I: Understanding the Challenge

Teacher Guide Course overview and teaching sequence

Course summary

Read the specification, examine the data and plan a real hackathon project. This lesson uses a practical classroom situation: A small team receives a dataset and must propose a genuinely useful AI-powered tool.

By the end: learners should be able to describe each topic using an input, an algorithmic step and an observable result, then run a small Python example and identify one limitation.

1. Turn a problem into inputs and outputs

1.1. Real-life situation

A challenge says 'help students choose study sessions'.

1.2. Understanding the concept

Translate a story into a precise deliverable: what data do we have, what decision is expected, and how will success be measured?

1.3. Worked example

Input: student availability and preferences; output: a recommended timetable.

1.4. Try it in Python

challenge = {'input':'availability.csv','output':'recommendations.csv'}
print(challenge)

2. Inspect data before modelling

2.1. Real-life situation

A file has duplicate rows, missing values and unclear units.

2.2. Understanding the concept

Use a small data dictionary and simple plots to understand a dataset before selecting an algorithm.

2.3. Worked example

Ten records with two missing labels do not give ten labelled training examples.

2.4. Try it in Python

rows=[{'label':'A'},{'label':None}]
print(sum(r['label'] is None for r in rows))
See the algorithm step by step
  1. Count records
  2. Inspect missingness
  3. Identify target column

3. Choose a simple baseline

3.1. Real-life situation

The team is tempted to start with a neural network.

3.2. Understanding the concept

A baseline is a small system that already works and can be measured. It may be a rule, a most-frequent-class prediction, or a simple tree.

3.3. Worked example

If 7/10 training labels are 'yes', always guessing 'yes' is a baseline; it may be inadequate but it sets a comparison point.

3.4. Try it in Python

labels=['yes']*7+['no']*3
print(labels.count('yes')/len(labels))
See the algorithm step by step
  1. Implement the simplest method
  2. Measure its score fairly
  3. Document its weaknesses

Try this: change one input or value in the code, then predict the new output before running.
