Week 12 · Homework

FiiCode I: Read the Challenge and Establish a Baseline

Teacher Guide One 60-minute session; core + optional Research

Learning outcome

Define the prediction problem; audit 240 synthetic examples; establish a 15/45 baseline.

Teaching sequence

0–10 introduce the use case; 10–23 identify five features and labels; 23–39 inspect CSV; 39–51 measure the baseline; 51–60 discuss leakage.

Core: reproducible observations, one experiment and an explanation in ordinary language. Research (3p): additional mathematics, model investigation or application engineering. All features and labels in this project are synthetic; do not infer student traits or real room conditions.

Independent preparation project: these are deliberately simulated examples for practising data analysis and software engineering. They are not official FiiCode rules, datasets, judging criteria or submissions.

The same study-space dataset, baseline and application are used in every homework from Week 12 to Week 15. Submit evidence, not just a final number.

Project starter ZIPProblem and file layout

Mandatory — inspect the dataset (1p)

Use the supplied train.csv and validation.csv. Produce audit.md with a five-column feature dictionary: each feature's unit, allowed range and one sample value. Report total examples and label counts in both splits.

Acceptance: exactly 150 training and 45 validation rows, split class counts of 50 and 15 respectively, and explicit acknowledgement that all examples are synthetic.

Homework — implement a baseline (2p)

Create baseline.py that reads the CSV, determines the most frequent training label and uses it to classify all 45 validation rows. Use alphabetical label order when training frequencies tie. Save the output in baseline-report.txt.

Required output: Constant prediction: avoid and Validation accuracy: 15/45. Include a sentence explaining why this is a valid comparison even though the score is low.

Research — controlled label imbalance (3p, optional)

Create a copy of training data with a different class distribution; never overwrite the canonical dataset. Predict how the constant baseline's label and score would change, then measure it. Explain why comparing altered validation sets would be unfair.

Delivery contract

Produce the named files, record original and modified results, and export them through the corresponding Laboratory submission panel. The named ZIP is prepared locally; teacher collection is a separate step.
