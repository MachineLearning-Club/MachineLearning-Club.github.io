Week 12 · Advanced

FiiCode I: Read the Challenge and Establish a Baseline

Teacher Guide One 60-minute session; core + optional Research

Learning outcome

Define the prediction problem; audit 240 synthetic examples; establish a 15/45 baseline.

Teaching sequence

0–10 introduce the use case; 10–23 identify five features and labels; 23–39 inspect CSV; 39–51 measure the baseline; 51–60 discuss leakage.

Core: reproducible observations, one experiment and an explanation in ordinary language. Research (3p): additional mathematics, model investigation or application engineering. All features and labels in this project are synthetic; do not infer student traits or real room conditions.

Independent preparation project: these are deliberately simulated examples for practising data analysis and software engineering. They are not official FiiCode rules, datasets, judging criteria or submissions.

Optional mathematical investigations. Read the Course before beginning; these proofs and derivations are not required to complete the 60-minute core lesson. Use your browser’s print command for a printable version.

Contents
  • Proof A — the optimal constant classifier
  • Proof B — the effect of intentionally balanced labels
  • Investigation C — how leakage invalidates an estimate

Proof A — the optimal constant classifier

Let the training label counts be n₀, n₁, n₂ with n=n₀+n₁+n₂. A predictor that always returns class c gets exactly n_c training predictions right. Therefore, among constant classifiers, choosing a class of maximum frequency is optimal on that dataset.

Proof

Any constant predictor c has correct count nc, which cannot exceed max(n₀,n₁,n₂). Predicting a majority class achieves this upper bound. QED.

Exercise: explain why this proof says nothing about whether the majority-class rule is optimal among all possible classifiers. Construct a dataset where a rule using Wi-Fi perfectly predicts a label but the constant predictor cannot.

Proof B — the effect of intentionally balanced labels

The training and validation sets have exactly the same number of examples for each of three classes. Any fixed single-class predictor therefore succeeds on precisely one third of the validation rows, regardless of which class it chooses.

Exercise: if 90% of future inputs are of a single class, what would happen to the constant classifier's apparent accuracy? Why can't a class-balanced classroom validation result tell us how frequently a label occurs in a real school?

Investigation C — how leakage invalidates an estimate

Imagine copying ten validation rows into training and allowing a k=1 nearest-neighbour model to find those exact copies. Assuming each identical row has its original label and no conflicting duplicates, the copied cases can be trivially memorised.

Exercise: identify the statistical assumption being violated. State a stronger splitting protocol and explain why separate IDs alone are not sufficient when two IDs describe the same original example.

References and reproducibility

All numeric claims can be reproduced with the same Python evaluation script and data. For Python input, output and basic mathematical notation, consult the club Python guide.
