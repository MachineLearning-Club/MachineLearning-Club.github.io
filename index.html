Machine Learning Club

Understand something → experiment with it → modify it → use it to solve a problem.

15 sessions across three modules, from algorithms and data to neural networks, software engineering and a final competition-style project.

How to use this club

Start with prepared Python examples and datasets. Laboratories are designed for direct browser experiments; GitHub is introduced later, not required to begin.
