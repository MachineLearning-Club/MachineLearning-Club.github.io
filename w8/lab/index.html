Week 08 · Laboratory

Computer Vision

Pixels as arrays, spatial filtering and image features.

10 Feb 2027One weekly session · 60 minutes
CourseLaboratoryHomeworkAdvanced

Laboratory learning objectives

  1. Inspect image pixel values
  2. Apply an edge filter
  3. Compare before-and-after images

Guided laboratory tasks

  1. Read a tiny grayscale array
  2. Calculate one 3×3 edge-filter result by hand
  3. Use OpenCV to visualise a filtered image

Work using PRIMM: Predict, Run, Investigate, Modify, Make. Starter code and AI assistance are allowed if you can explain the result.

Evidence to keep

A concise worked calculation, a code/notebook result, and a written explanation of one error or limitation.
