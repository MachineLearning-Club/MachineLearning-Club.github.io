Revision: Computer Vision and Neural Networks

Teacher Guide Course overview and teaching sequence

Course summary

Connect image pixels, learned features and predictions. This lesson uses a practical classroom situation: A classroom sketch-recognition demo must be accurate on drawings it has never seen.

By the end: learners should be able to describe each topic using an input, an algorithmic step and an observable result, then run a small Python example and identify one limitation.

1. From pixels to predictions

1.1. Real-life situation

A student draws a digit on a small canvas.

1.2. Understanding the concept

Image pixels become input numbers, a preprocessing step rescales them, and a learned classifier predicts a label.

1.3. Worked example

A grayscale 8×8 image contains 64 values; a digit model might use those 64 numbers as features.

1.4. Try it in Python

image = [[0]*8 for _ in range(8)]
image[3][4]=255
print(image[3][4])
See the algorithm step by step
  1. Draw a shape
  2. Read its pixels
  3. Predict its class

Try this: change one input or value in the code, then predict the new output before running.

2. Revision: what models actually learn

2.1. Real-life situation

A digit looks different when tilted.

2.2. Understanding the concept

Thresholding filters adjust pixels by a rule; neural networks learn weighted transformations from examples.

2.3. Worked example

Changing brightness can affect a rule-based threshold and the neural model differently.

2.4. Try it in Python

print('Pixels → preprocessing → model → label')
See the algorithm step by step
  1. Observe an input transformation
  2. Compare two model predictions
  3. Identify the source of the difference

Try this: change one input or value in the code, then predict the new output before running.

Bibliography: pyml.ro: Python & Machine Learning for high-school students.

3. Reading an evaluation result

3.1. Real-life situation

A model correctly recognises 18 of 20 held-out digits.

3.2. Understanding the concept

Accuracy = correct / total; a confusion matrix shows which types of mistakes happened. Test data must not be used during training.

3.3. Worked example

18/20=90%, but both mistakes might involve the same digit, so inspect errors by class.

3.4. Try it in Python

correct,total=18,20
print(f'{100*correct/total:.0f}%')
See the algorithm step by step
  1. Calculate accuracy
  2. Count errors by class
  3. Describe one weak case
