Week 08 · Homework

Revision: Computer Vision and Neural Networks

Situation — a school is testing a handwritten-digit reader

Teachers want a tool that can read numbers written on paper slips. The prototype correctly identifies many examples but makes some mistakes. Your job is to decide whether the claim “The reader works reliably on every handwriting style” is supported by the evidence.

Available evidence: real 8×8 digit images (64 features per image), 600 labelled training images, 200 held-out images, and a k-nearest-neighbour classifier. With original pixel values and k=3, the classifier predicts 196 of the 200 held-out digits correctly. Some of the first errors occur at held-out example #17 (actual 1, predicted 8), #27 (actual 9, predicted 8), #128 (actual 5, predicted 1) and #138 (actual 8, predicted 1).

Mandatory (1p) — understand what the score proves

  1. Calculate the accuracy and error rate using correct=196 and total=200. Show the fractions and percentages.
  2. Explain why the accuracy describes a fixed test subset and does not guarantee correct recognition for every new person's handwriting.
  3. Explain in one sentence why the test labels must not be used when finding nearest neighbours.
Check your arithmetic

Accuracy: 196/200=98%. Error rate: 4/200=2%. This supports a claim about these 200 withheld examples, under the stated model settings, not every handwriting sample in the world.

Homework (2p) — investigate an actual mistake

Open the Week 8 interactive laboratory and select test example 17. It is a real held-out image from the provided dataset, not a synthetic drawing.

  1. Record the known digit, model's predicted digit and three nearest training labels with squared distances.
  2. Change only k between 1, 3 and 5. State whether the predicted label changes for this image.
  3. Restore k=3 and compare raw pixel values against threshold 8. Do not claim the threshold improves the model without checking the entire 200-image evaluation.
  4. Use the notebook to compute held-out accuracy for both raw and thresholded features, then describe which condition is stronger on this fixed sample.
  5. Write a short verdict: would you deploy the reader without a human checking ambiguous digits? Explain why or why not.
Suggested report format
Model: 3-nearest neighbours, squared pixel distance
Dataset: 600 training images, 200 held-out images
Original accuracy: 196/200 = 98%
Observed error: Test #17 · actual 1 · predicted 8
Changed parameter: ...
Result: ...
What this does NOT prove: ...

Research (3p) — optional

Propose a separate development/validation set to select the threshold or k, and preserve a final untouched test collection. Explain in your own words why trying twenty thresholds and reporting the best result on the same exposed test set could make the result misleading. No additional packages are required.

What to submit

One notebook or .py file showing the two tested configurations and a concise report (PDF, TXT or notebook Markdown) with the evidence table and reasoning. Use the Week 8 local submission ZIP preparation. It creates files locally; your teacher must still tell you where to submit them.
