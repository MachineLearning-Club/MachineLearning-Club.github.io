Revision: Computer Vision and Neural Networks

Advanced Problem Sheet — handwritten-digit classification

These five optional problems investigate the mathematics behind the Week 8 classifier. They use real data and finite calculations rather than calculus or neural-network backpropagation. Try each before opening its solution.

Known data: 64 pixel values per digit, each 0–16, and a fixed split of 600 training images and 200 held-out images.

Worked Example A — why use the square of the distance?

Suppose three pixel values of an unseen image are Q=(2,1,3), and a labelled stored image is A=(2,2,3). Squared distance is d²(Q,A)=(2−2)²+(1−2)²+(3−3)²=1. If another example is B=(5,3,3), the squared distance is 9+4+0=13.

The ordinary Euclidean distances are √1=1 and √13≈3.61. Because square roots preserve the order of nonnegative values, comparing 1 and 13 is enough to decide which example is closer. The same reasoning works for all 64 features.

Problem 1 — calculate the nearest neighbour

Query: Q=(3,5,2). The stored labelled examples are A=(1,4,2) with label 0, B=(4,6,2) with label 7, and C=(3,5,6) with label 2. Calculate all three squared distances, then state the 1-NN prediction.

Worked solution
  1. d²(Q,A)=2²+1²+0²=5.
  2. d²(Q,B)=(−1)²+(−1)²+0²=2.
  3. d²(Q,C)=0²+0²+(−4)²=16.
  4. B is nearest, so the prediction is its known label 7.

Problem 2 — majority voting, ambiguity and tie rules

Three nearest neighbours have labels 8, 1, 8, and squared distances 693, 791, 704 respectively. Determine the k=1 and k=3 predictions.

Worked solution

The smallest distance is 693, labelled 8, so 1-NN predicts 8. For k=3, label 8 receives two votes and label 1 receives one vote. Therefore 3-NN also predicts 8. These are actual nearest-neighbour distances for our held-out image #17 (known label 1), showing why a plausible vote can still be wrong.

Extension: suppose four neighbours vote twice for 1 (distances 2 and 10) and twice for 8 (distances 4 and 5). The tie rule in our implementation chooses the class with the smaller sum of distances, so it selects 8 because 9 is less than 12. The tie rule is an explicit design choice.

Problem 3 — a confusion matrix and two different statistics

An imaginary classifier distinguishes only digit 0 from digit 1. Its results are:

Actual \ Predicted01
0123
1213

Compute: total cases, correct cases, accuracy, and recall for digit 1. Explain why accuracy and recall answer different questions.

Worked solution
  1. Total = 12+3+2+13=30.
  2. Correct = 12+13=25, accuracy 25/30≈83.3%.
  3. There are 2+13=15 actual ones, and 13 were correctly found. Recall for digit 1 is 13/15≈86.7%.
  4. Accuracy measures correctness across all cases, recall looks only at a particular actual class.

Problem 4 — prove that uniform brightness scaling preserves nearest-neighbour order

Suppose every pixel value in the query and every training image is multiplied by a fixed positive constant c. Show that squared Euclidean distance becomes c² times its original value, and argue that the nearest neighbour stays the same.

Worked proof

For vectors A and B, d²(cA,cB)=Σᵢ(caᵢ−cbᵢ)²=Σᵢc²(aᵢ−bᵢ)²=c²Σᵢ(aᵢ−bᵢ)²=c²d²(A,B). Because c²>0, if one distance was less than another before scaling, it remains less afterwards. Every neighbour ordering remains the same, so a deterministic k-NN prediction is unchanged. Careful: clipping, rounding, scaling only some images, or thresholding are not the same transformation; they can change results.

Problem 5 — can repeated test-set tuning invalidate an honest report?

A pupil examines 25 preprocessing thresholds, records the 200-image held-out accuracy for each, chooses the best threshold and reports that value as a completely untouched final test result. Identify the mistake. Propose a three-way split.

Worked reasoning

The pupil used the visible test labels to choose a model setting. That makes the test set part of the selection process, so the reported best result is no longer an independent final evaluation. A stronger design uses training to build models, validation to choose thresholds/k, and a separate test set once for the final report. Our small classroom subset is specifically for exploration; its scores should not be advertised as final performance on other handwriting.
