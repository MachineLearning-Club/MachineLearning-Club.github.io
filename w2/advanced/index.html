Week 02 · Advanced

Supervised Learning: ID3

From a decision rule to a justified algorithm

These exercises are optional. They extend Week 2 from a useful classroom classifier to a more precise understanding of why ID3 chooses an attribute and why that choice is not a universal guarantee of the smallest tree.

Reference formulas

EntropyH(S)=−Σ p(class)log₂ p(class)
After a splitH(S | feature)=Σ (|group|/|S|) × H(group)
Information gainIG(feature)=H(S)−H(S | feature)
Leaf decisionOne label if a subset is pure; otherwise the majority label when no features remain

Reasoning exercises

1. Understand pure and mixed nodes

A model receives three groups of labelled items: [5+,0−], [3+,3−] and [1+,3−].

  1. Which group has entropy zero?
  2. Which has the largest possible entropy for a binary label?
  3. Find the entropy of [1+,3−] to three decimal places.
Hint

For [1+,3−], use p=yes=1/4 and p=no=3/4. A perfectly balanced binary group has entropy 1.

Show solution

Pure [5+,0−] has entropy 0. Balanced [3+,3−] has entropy 1. The third group has −1/4×log₂(1/4) − 3/4×log₂(3/4) ≈ 0.811 bits.

2. Do all questions reduce uncertainty equally?

There are eight labelled examples: four yes and four no. Question A creates two groups: [4+,0−] and [0+,4−]. Question B creates two groups: [2+,2−] and [2+,2−].

  1. Compute the entropy before either question.
  2. Compute the conditional entropy after A and after B.
  3. Find IG(A) and IG(B). Explain the result without using the formulas.
Show solution

Before: H=1. For A, both groups are pure: H(after)=0, so IG(A)=1. For B, both groups are equally mixed: H(after)=1, so IG(B)=0. A perfectly distinguishes the labels; B leaves them as uncertain as before.

3. Why must the branch entropy be weighted?

A dataset contains ten labelled rows: nine in a group of [5+,4−], one in a pure [0+,1−] group.

  1. Calculate the entropy of the nine-row group (approximately).
  2. Calculate the weighted conditional entropy. Do not average the two groups as if each contained five records.
  3. Explain why an isolated pure record does not make a split exceptionally informative.
Show solution

H([5+,4−])≈0.991. Conditional entropy is 9/10×0.991 + 1/10×0 ≈ 0.892. Starting entropy is H([5+,5−])=1, so the gain is approximately 0.108 bits. The larger mixed group dominates the weighted average.

4. A tree that memorises too closely

Suppose a dataset contains a random identifier column that uniquely names every training example. A tree can create one branch per identifier and reproduce all the training labels.

  1. Why can the training accuracy reach 100%?
  2. Will a brand-new identifier have a known branch?
  3. Explain why the identifier is a poor feature for predictions about genuinely new students or events.
Show solution

Memorising each identifier can achieve perfect training accuracy, but a new identifier has not appeared during training. A useful feature should relate to the phenomenon being predicted and should generalise beyond the recorded examples.

5. Greedy tree construction can miss a smaller tree

Consider four labelled Boolean records. The output is a function of A and B, but the dataset also includes a third feature C that happens to give a useful first split.

  1. Compute the information gain for A, B and C.
  2. Which attribute does a greedy information-gain strategy prefer?
  3. Notice the simpler rule label = A XOR B. Draw a decision tree using just A and B.
  4. Compare its maximum path length with the ID3 tree and explain why greedy means “best now”, not “globally smallest”.
Hint

Both A and B have zero root gain. C splits off one negative example and leaves three mixed examples, so C has positive gain.

Show solution

The starting label distribution is [2+,2−] with H=1. A and B each create two [1+,1−] groups → gain 0. For C, one group is [0+,1−] and the other [2+,1−], giving IG(C)=1−3/4×H(2/3)≈0.311. ID3 chooses C, then needs A and B within the mixed branch, yielding a longer path. The XOR rule can be represented by branching on A and then B, depth 2. This exercise is an adaptation of the reasoning in Ciortuz, §4.1.1, solved problem 4.

Worked connection to Week 3

Both decision trees and K-means repeatedly make local choices. ID3 selects the feature that reduces label uncertainty. K-means assigns points to the nearest centre and moves centres to reduce squared distance. In neither case should “the algorithm ran” be confused with “the result is meaningful for the real-world problem”.
