Week 02 · Laboratory

Mathematics for Machine Learning

Statistics, probability and information theory on small labelled datasets.

9 Dec 2026One weekly session · 60 minutes
CourseLaboratoryHomeworkAdvanced

Laboratory learning objectives

  1. Summarise a labelled dataset
  2. Calculate two class probabilities
  3. Compare entropy across distributions

Guided laboratory tasks

  1. Compute frequency counts and means by hand
  2. Plot the same data with Python
  3. Change one label and remeasure uncertainty

Work using PRIMM: Predict, Run, Investigate, Modify, Make. Starter code and AI assistance are allowed if you can explain the result.

Evidence to keep

A concise worked calculation, a code/notebook result, and a written explanation of one error or limitation.
