Week 02 · Laboratory

Supervised Learning: ID3

Learn a tree by asking the most informative questions.

Lab challenge

Build the same outdoor-activity classifier by hand and in Python.

Laboratory objectives

Compare feature questions using information gain, distinguish the interactive CART demonstration from categorical ID3, and implement a small decision tree in Python without hiding the algorithm behind a library call.

Suggested hour: 8 min paper prediction · 12 min interactive · 23 min Colab · 12 min modification · 5 min conclusion.

1. Predict — before using a computer

From the eight-row table in the Course, count the number of yes/no answers. Guess which of sky, wind and temperature should be the first question and justify the guess using the labels.

Do not calculate every logarithm immediately. First describe what it means for a split to make a subset pure.

2. Experiment — information gain

The exercise below uses the same eight records from the Course. Select a candidate first question. The entropy and information gain are recalculated locally in your browser; no data is sent to a server.

Select a feature and calculate its gain.

Then compare the result with a visual tree-building app. This external app illustrates CART rather than the categorical ID3 procedure we are calculating here.

4. Reflection

Why does ID3 terminate immediately when a node contains only one class? What can happen if a training example is missing? Which parts of the tree were chosen by data rather than by a human writing the final rules?

Exit ticket: Explain why sky is chosen as the root and give one reason the resulting model could still fail on new observations.
