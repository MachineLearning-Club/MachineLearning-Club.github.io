Lab challenge — recognise real handwriting, honestly

Your school's fictional digit reader is being evaluated before anyone relies on it. You have 600 labelled training images and 200 different labelled images reserved for testing. Each is an 8×8 grid of values 0–16. Your goal is not to obtain a flawless-looking demonstration: it is to explain exactly what the classifier does and which mistakes it makes.

By the end: produce a working notebook, a concise evidence table and an explanation of one observed error. No GitHub or account is required. This exercise uses real labelled digit examples from scikit-learn's digits distribution.

1. Before running the model: read the data

  1. Predict the label for example 1 from its picture alone. Then read its actual label.
  2. Count the rows and columns. How many numbers does the model compare for one image?
  3. Inspect one dark and one pale pixel. Explain what 16 and 0 mean in this dataset.
  4. Record an initial hypothesis: will turning an 8×8 grey image into black and white always improve recognition?

3. Run and change the actual Python classifier

The notebook contains the identical fixed dataset in compressed form, so no external package or internet dataset request is needed after opening it. It uses standard Python arithmetic, sorting and lists.

Download Week 8 notebook · Run in JupyterLite · Notebook tutorial

  1. Predict the notebook's starting accuracy before running its evaluation cell.
  2. Run the cells in order. Check that the model classifies the same held-out examples as the website.
  3. Change K from 3 to 1 in its designated cell and rerun the prediction/evaluation cells. Record the result.
  4. Change only the threshold setting and rerun. Do not edit the underlying test labels or copy the test images into the training set.
  5. Identify one misclassified example and explain what the closest training examples suggest.

Why not just print the image's label?

Because that would not be a prediction. The notebook must calculate a distance from the image's 64 numbers to training images and select a label from those training examples. It may use the test label only afterwards, to evaluate whether the prediction was correct.

4. Interpret the evidence

Choose a mistaken held-out example, such as #17 with known label 1 and predicted label 8 under default settings. Write three concise sentences:

  1. Evidence: identify the index, known digit, predicted digit and one nearest labelled training example.
  2. Explanation: describe a visual similarity or ambiguity; distinguish what you observed from what you assume.
  3. Next test: propose one controlled change and explain how you would determine if it helps rather than making claims from a single image.
Research (3p) — optional

Compare k=1, k=3 and k=5 on the same test subset, record all three scores, and draw a small table of how often the model confuses two specific digits. Discuss why selecting k repeatedly based on the exposed test scores does not give an unbiased final estimate. Propose a separate validation set for choosing k.
