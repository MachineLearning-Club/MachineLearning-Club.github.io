1. Compute four outputs without a computer

The recycling-station model uses z=w₁x₁+w₂x₂+b and returns 1 if z≥0. Let w₁=w₂=1, b=−1.5.

  1. Complete the four-row truth table for inputs (0,0), (1,0), (0,1), (1,1).
  2. Which input is the only one that produces a positive result?
  3. Change only the bias to −0.5. Predict two values that will change.
Check

The four original weighted sums are −1.5, −0.5, −0.5, 0.5, giving outputs 0,0,0,1 (AND). With bias −0.5 the outputs become 0,1,1,1 (OR).
