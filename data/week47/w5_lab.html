1. Begin with a tiny synthetic worksheet

Before editing, draw the original 5×5 array of pixel intensities. Find the darkest nonzero cell, count the number of light-background cells, then predict which squares represent writing.

  1. Toggle one light pixel so that it becomes dark. Does a binary speck appear?
  2. Raise the threshold to 200. Which background pixels now become black?
  3. Compare the Original and 3×3 mean views. Why might smoothing help or hurt handwriting?

Checkpoint: each square should change immediately; record one before/after intensity, not just a subjective impression.

2. Convert one RGB pixel into grayscale

Change the channels and compare a simple mean against a weighted luminance-style conversion. Start with R=120, G=180, B=240; predict which formula gives 180.

  1. Compute the simple mean on paper.
  2. Set RGB to (255,0,0). Compare it with (0,255,0) using the weighted formula.
  3. Explain why green contributes more to the weighted brightness in this particular convention.
