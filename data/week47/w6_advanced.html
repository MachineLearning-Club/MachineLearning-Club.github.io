Derive what a perceptron can represent and learn

Optional exercises extend the Boolean AND dataset and the arithmetic update rule. Ciortuz §6.1.1 and §6.1.2 supply the underlying threshold-neuron and learning examples; these questions adopt a consistent 0/1 output convention.

Reference

z=w₁x₁+w₂x₂+b, ŷ=1 if z≥0 else 0, and when a training example is wrong: wᵢ←wᵢ+η(t−ŷ)xᵢ, b←b+η(t−ŷ).

Five worked challenges

1. Construct OR and AND from parameters

Use w₁=w₂=1. Find two bias values: one that implements OR and one that implements AND on binary inputs. Show all four outputs for each.

Solution

b=−0.5 gives OR outputs [0,1,1,1]; b=−1.5 gives AND outputs [0,0,0,1] in the order (0,0),(1,0),(0,1),(1,1).

2. Calculate a mistaken classification and update

Start w=(0,0), b=−1 and train on (1,1) with target 1 and η=0.5. Find prediction, error and all updated values; calculate the next prediction for the same input.

Solution

Initial weighted sum −1 gives 0. Error t−ŷ=1, so w becomes (0.5,0.5), bias −0.5. New sum is 0.5, which gives 1 on the corrected example.

3. Why does the bias update for zero-valued inputs?

Start w=(1,1), b=0.5 and train on (0,0) with target 0 and η=0.5. Calculate the update. Why do the weights remain unchanged?

Solution

Prediction 1 is wrong: t−ŷ=−1. Both weight changes are η(−1)×0=0, but b decreases by 0.5 to zero. With the convention step(0)=1, the same input remains misclassified at b=0; another mistake update is required to reach a negative bias.

4. Prove XOR is not linearly separable

Positive XOR examples are P=(1,0), Q=(0,1), while negative examples are R=(0,0), S=(1,1). Consider the midpoint of each pair. Use convexity of half-planes to show no strict linear separation exists.

Solution

The midpoint of P and Q is (0.5,0.5), and so is the midpoint of R and S. If one open half-plane contained both positives, it would contain their midpoint. The other disjoint open half-plane containing both negatives would contain the same point. Contradiction.

5. Does convergence depend on the training data?

Two records have identical inputs (1,0) but opposite target labels 0 and 1. Can a deterministic perceptron obtain zero errors on both records simultaneously?

Solution

No. A fixed deterministic function must return the same output for identical input coordinates. The two contradictory labels cannot both be satisfied by any deterministic classifier. A convergence guarantee for linearly separable consistent data cannot apply here.
