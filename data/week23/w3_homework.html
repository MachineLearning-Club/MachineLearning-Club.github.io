Real-life situation — where should two collection points go?

A delivery service has five parcel locations marked on a simple grid, and can afford only two shared collection points. It wants locations that keep squared travel distance small.

Download delivery-points.csv. The first task uses the five points you saw in the Course and Laboratory. The second applies the algorithm to an enlarged neighbourhood.

Mandatory (1p) — Work out a complete iteration

Use A(−1,0), B(1,0), C(0,1), D(3,0), E(3,1) and two starting centroids μ₁=(−1,0), μ₂=(3,1).

  1. Plot all five points on squared paper or use the laboratory graph.
  2. For B(1,0), compute both squared distances to the initial centroids; select the nearer one.
  3. Assign all five points to their nearest initial centroid. Write the two sets of point names.
  4. Calculate the new centroid of each group by averaging the x and y coordinates separately.
  5. Evaluate the squared-error total before and after the update and decide whether it decreased.
Formulas to use
  1. Squared distance: d²((x,y),(a,b)) = (x−a)² + (y−b)². You can omit the square root when comparing distances.
  2. Cluster centroid: μ = (sum of x values / number of points, sum of y values / number of points).
  3. Total squared error: J = Σ d²(point, assigned centroid).
Check the result after working it out

First groups: {A,B,C} and {D,E}. Updated centres: (0,1/3) and (3,1/2). Squared-error total decreases from 7 to 19/6 ≈ 3.167.

Homework (2p) — Simulate a larger neighbourhood

The company now has ten delivery locations. Use the pre-filled Delivery Zones notebook, which already contains the extra locations and plotting functions. You can also download the ten-location CSV for reference.

  1. Run the original notebook and save its first graph showing the ten points.
  2. Set K=2 and use the indicated initial centres. Run until no assignments change.
  3. Create a simple table of cluster members and final centroid coordinates.
  4. Plot the final cluster colours and both centroids. Label the x and y axes.
  5. Change the starting centroids to two other listed delivery locations. Rerun. Did you obtain the same clusters and same squared error?
  6. Explain whether the two centroid positions are necessarily useful actual collection-point sites. What real-world information is missing from this toy map?
Algorithm to adapt
  1. Start with two centroid coordinates.
  2. For every delivery point, calculate squared distance to each centroid and assign it to the nearer one.
  3. Replace each centroid with its group's average coordinate.
  4. Repeat until groups stop changing or 20 iterations are reached.
  5. Record the final squared-error total.
What do I need to program?

Only change the starting coordinates and optionally the number of iterations in the provided notebook. The plotting helper and dataset are ready to run. For a more technical attempt, implement the assign/update loop yourself after observing it work.

Research (3p) (optional)

Add a location at (20,20) and rerun. Which centroid moves the most? Compare your results before and after. Explain why a single faraway point can be important when groups are represented by arithmetic means.
