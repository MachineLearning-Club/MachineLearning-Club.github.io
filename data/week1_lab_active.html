1. Quick, Draw! — can a model guess your sketch?

The AI sees your drawing as you make it and predicts an object category.

Open Quick, Draw! ↗ No login · Drawing

  1. Play one complete round (six sketches).
  2. Write down one correct guess and one wrong or late guess.
  3. Try an unusual but recognisable drawing. Did the model understand it?
What is the model actually doing?

Input: drawn strokes. Processing: a trained drawing recogniser estimates a category from those strokes. Output: its current guess. It was trained before you opened the game.

2. Hugging Face Pixel Search — search by meaning

The search engine finds pixel-art images using semantic similarity, not only exact word matches.

Open Pixel Search — “earth” ↗ Public static Space · No HF token

  1. Start with earth. Inspect the pictures ranked near the top.
  2. Try planet and world. Which pictures remain similar?
  3. Try red planet and then red fruit. Record a surprising result.
Why can different words retrieve similar pictures?

Models may convert descriptions and images into numerical representations. Search compares those representations using a similarity measure. A near match is not proof the result has the meaning you intended.

The model may download data on first use; this activity needs a modern browser and an internet connection. If it is slow, continue with Activity 3.

5. Generate an interactive coffee-shop website

Use one free generative AI tool to turn a detailed description into working HTML, CSS and JavaScript.

Your prompt

Choose a generator: these tools offer free access without an account, though some have usage or device limits.

Generate and preview HTML ↗

Free without signup; runs in-browser when supported, otherwise via its server.
Duck.ai

Ask a chatbot to produce HTML ↗

Free, no required account; daily usage limits.
Free.ai HTML Generator

Try an HTML generator ↗

Free models available without signup; some premium models require payment.
  1. Choose a theme, colour and mascot; copy the prompt to your chosen tool.
  2. Check that the generated page includes a menu, an Add to cart control and a cart total.
  3. Add two coffees. Does the displayed sum match the listed prices?
  4. Try the checkout button. It must only simulate an order, never accept real payment details.
How should you judge a generated website?

Verify that its buttons actually change the cart; prices add correctly; the text is readable on a small screen; and checkout is explicitly labelled as a demonstration. A convincing screenshot is not evidence of functioning software.
