Situation — a school newsletter contains an AI-generated mistake

A volunteer asks an AI writing assistant to summarise the results of a fictional anonymous poll. The draft claims 80% approved, but the recorded counts are 12 yes and 8 no. Your task is to check the number and write a corrected sentence before it is published.

Mandatory (1p)

  1. Write the formula percentage = yes / (yes + no) × 100.
  2. Calculate the real percentage for yes=12, no=8.
  3. Circle the unsupported claim in the AI-generated sentence.
  4. Write a corrected sentence that uses only the known figures.
Answer after attempting

12/20×100=60%. A supported sentence is: “In the fictional poll, 12 of 20 votes (60%) were yes.” The vote counts alone do not explain why anyone chose that answer.

Homework (2p) — implement a simple check

  1. Open the Week 10 Laboratory and run the example in browser Python.
  2. Define def percentage(yes, no) and return the correct number.
  3. Test (12,8) and (3,2). Both should return 60%.
  4. When the total is zero, return a clear warning rather than dividing by zero.
  5. Create a small three-column table: original AI claim / independent data / corrected claim.

Research (3p) — optional

A fictional social feed has click counts music=8, science=2, sport=0. Implement a ranking and show how adding 9 science clicks changes the order. Explain why clicks are not proof of someone’s genuine preference and why a real recommender should not make decisions about pupils from these counts alone.
