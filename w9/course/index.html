1. Review the core ideas

Real-life question. An evaluator asks whether a solution should use fixed rules, ID3, K-Means or a neural network.

Choose algorithms based on the form of available data and the desired result, not their popularity.

Worked example.

Known class labels → supervised learning; unknown groups → clustering; known sensor rules → conventional programming.

problems = ['thermostat','cluster points','classify labelled points']
print(problems)
Show the process step by step
  1. Identify inputs
  2. Check for labels
  3. Choose the solution type

2. A practical evaluation procedure

Real-life question. A classifier receives new points and produces labels.

A fair evaluation uses examples that were not included in training and reports results clearly.

Worked example.

If 7 of 10 held-out cases are correct, accuracy is 70%; explain two failures.

predictions=['A','B','A']; actual=['A','A','A']
print(sum(a==b for a,b in zip(predictions,actual)))
Show the process step by step
  1. Keep test data separate
  2. Run predictions
  3. Record both successes and failures

3. Explain a model visually

Real-life question. The teacher sees a model's answer but does not know how it was produced.

A useful technical explanation names the input, transformation, output and limitation. Diagrams are as valuable as code for this task.

Worked example.

A pixel image becomes a number grid, then hidden neuron activations, then a predicted digit.

print('Input → transform → predict → evaluate')
Show the process step by step
  1. Draw the pipeline
  2. Show one intermediate value
  3. State a limitation
