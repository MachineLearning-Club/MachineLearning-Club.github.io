Week 09 · Laboratory

Perceptrons and Neural Networks

Weighted sums, bias, activation and layered networks.

17 Feb 2027One weekly session · 60 minutes
CourseLaboratoryHomeworkAdvanced

Laboratory learning objectives

  1. Calculate neuron outputs
  2. Adjust weights to change decisions
  3. Inspect an interactive network

Guided laboratory tasks

  1. Calculate four binary perceptron outputs
  2. Change one weight and observe changes
  3. Test a neural-network playground

Work using PRIMM: Predict, Run, Investigate, Modify, Make. Starter code and AI assistance are allowed if you can explain the result.

Evidence to keep

A concise worked calculation, a code/notebook result, and a written explanation of one error or limitation.
