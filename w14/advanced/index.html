Week 14 · Advanced

FiiCode III: Improve, Measure and Test

Teacher Guide One 60-minute session; core + optional Research

Learning outcome

Compare candidates fairly on validation data; read a confusion matrix; report one error.

Teaching sequence

0–10 recall baseline; 10–25 compare k values; 25–42 error-analysis experiment; 42–53 controlled ablation; 53–60 freeze a setting.

Core: reproducible observations, one experiment and an explanation in ordinary language. Research (3p): additional mathematics, model investigation or application engineering. All features and labels in this project are synthetic; do not infer student traits or real room conditions.

Independent preparation project: these are deliberately simulated examples for practising data analysis and software engineering. They are not official FiiCode rules, datasets, judging criteria or submissions.

Optional mathematical investigations. Read the Course before beginning; these proofs and derivations are not required to complete the 60-minute core lesson. Use your browser’s print command for a printable version.

Derivation A — why the matrix diagonal equals correct predictions

Let Mᵢⱼ count validation rows with actual class i and predicted class j. A prediction is correct exactly when i=j, so correct predictions equal the sum of diagonal entries. Total predictions equal the sum of all entries.

Week 14 example

For k=1, the matrix rows are [13,2,0], [0,15,0], [0,2,13]. Correct = 13+15+13=41; total = 45. Accuracy = 41/45 ≈ 91.1%.

Exercise: compute recall(good)=13/15 and precision(consider)=15/19. Explain why these two quantities answer different questions.

Investigation B — validation selection bias

If you choose the model with the highest observed validation score among many candidates, you select not only true performance differences but also favourable sampling variation. The selected score can therefore be an optimistic estimate of new-data performance.

Exercise: imagine two equally good classifiers evaluated on small random validation sets. Explain why one of them can still appear better by chance. Why is a further untouched hold-out necessary before reporting a final score?

Experiment C — feature ablation

An ablation repeats a controlled experiment after disabling one factor. In the fixed example, k=1 with Wi-Fi weight 0.7 gives 41/45 correct on validation. With Wi-Fi weight zero, the result is 39/45.

The observed two-case difference is 2/45 ≈ 4.4 percentage points on this subset. It is not proof that Wi-Fi is universally helpful or that the original weighting is optimal.

Exercise: record which individual errors changed after the ablation. Determine whether the change improved recall for every class.

All numeric claims can be reproduced with the same Python evaluation script and data. For Python input, output and basic mathematical notation, consult the club Python guide.
