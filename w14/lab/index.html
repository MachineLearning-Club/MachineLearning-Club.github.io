Week 14 · Lab

FiiCode III: Improve, Measure and Test

Teacher Guide One 60-minute session; core + optional Research

Learning outcome

Compare candidates fairly on validation data; read a confusion matrix; report one error.

Teaching sequence

0–10 recall baseline; 10–25 compare k values; 25–42 error-analysis experiment; 42–53 controlled ablation; 53–60 freeze a setting.

Core: reproducible observations, one experiment and an explanation in ordinary language. Research (3p): additional mathematics, model investigation or application engineering. All features and labels in this project are synthetic; do not infer student traits or real room conditions.

Contents
  • 1. Compare candidate models before deciding
  • 2. Use the matrix to find a specific failure
  • 3. Remove one feature's influence
  • Submission

Independent preparation project: these are deliberately simulated examples for practising data analysis and software engineering. They are not official FiiCode rules, datasets, judging criteria or submissions.

1. Compare candidate models before deciding

Load the fixed 45 validation examples and calculate accuracy for k=1,3,5,7. Begin with a prediction: which k will be most accurate? Then run the actual code and compare against 15/45 for the constant baseline.

Keep the split fixed. If you generate new validation examples after seeing scores, you are no longer doing a controlled before/after comparison.

2. Use the matrix to find a specific failure

Change k and press Evaluate on validation set. Rows in the displayed matrix are actual classes and columns are predicted classes. Count how many predictions fall off the diagonal, and find a mistaken example.

Loading the classroom experiment…

For k=1, verify the diagonal is 13,15,13. Calculate the recall of good and report your result with numerator and denominator.

3. Remove one feature's influence

In the notebook, set the Wi-Fi weight to zero without altering the dataset, k or remaining weights. Repeat validation. The reference experiment changes from 41/45 to 39/45. Describe what changed and what did not.

Do not write “the Wi-Fi feature always improves recommendations.” The evidence is only an observed two-case difference on this public, synthetic validation set.

Deliverable: baseline comparison, k table, confusion matrix, error example, ablation table and the frozen setting k=1.

Research (3p): compare recall across classes before and after ablation, and explain whether the model might be unequal across classes despite similar overall accuracy.
