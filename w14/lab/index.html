FIICode: Error Analysis and Tuning

Prioritise experiments based on observed weaknesses.

31 Mar 2027One weekly session · 60 minutes
CourseLaboratoryHomeworkAdvanced

Laboratory learning objectives

  1. Inspect difficult cases
  2. Change one model variable
  3. Create a score comparison table

Guided laboratory tasks

  1. Inspect the worst model mistakes
  2. Change a single feature or parameter
  3. Compare score runtime and difficult cases

Work using PRIMM: Predict, Run, Investigate, Modify, Make. Starter code and AI assistance are allowed if you can explain the result.

Evidence to keep

A concise worked calculation, a code/notebook result, and a written explanation of one error or limitation.
