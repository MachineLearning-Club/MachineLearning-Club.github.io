Week 14 · Homework

FIICode III: Improving and Testing

Improve one thing at a time, using actual measurements.

Real-life situation

A hackathon project must persuade reviewers that its claimed improvement is real.

Mandatory (1p)

Record the baseline metric and two failed cases.

Suggested starting steps
  1. Open the Week 14 Laboratory and run the prepared code.
  2. Identify the relevant input and output.
  3. Change the smallest amount of code needed to solve the situation.

Homework (2p)

Implement one controlled change and explain its measured effect.

What to submit

Use the laboratory submission area to prepare a named notebook or Python file. Add one screenshot, output table or short explanation of what changed.
