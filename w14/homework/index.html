Week 14 · Homework

FiiCode III: Improve, Measure and Test

Teacher Guide One 60-minute session; core + optional Research

Learning outcome

Compare candidates fairly on validation data; read a confusion matrix; report one error.

Teaching sequence

0–10 recall baseline; 10–25 compare k values; 25–42 error-analysis experiment; 42–53 controlled ablation; 53–60 freeze a setting.

Core: reproducible observations, one experiment and an explanation in ordinary language. Research (3p): additional mathematics, model investigation or application engineering. All features and labels in this project are synthetic; do not infer student traits or real room conditions.

Independent preparation project: these are deliberately simulated examples for practising data analysis and software engineering. They are not official FiiCode rules, datasets, judging criteria or submissions.

The same study-space dataset, baseline and application are used in every homework from Week 12 to Week 15. Submit evidence, not just a final number.

Project starter ZIPProblem and file layout

Mandatory — model comparison (1p)

In validation_report.md, write a five-row table: constant baseline and k=1,3,5,7. Include correct counts and accuracy percentages for the same 45 validation examples.

Acceptance: baseline 15/45 and k results 41/45, 39/45, 39/45, 41/45. State which setting is selected and why.

Homework — investigate errors (2p)

Save the k=1 validation confusion matrix as confusion.csv with actual classes in rows and predicted classes in columns. Calculate recall for each class, identify at least one wrong case and produce ablation.md comparing default weights with Wi-Fi weight 0.

Acceptance: diagonal 13/15, 15/15, 13/15, and the Wi-Fi ablation score 39/45. Do not use final test labels to choose settings.

Research — test the stability of the choice (3p, optional)

Explain why the best k could change with a different validation split. Propose a repeated-split experiment while keeping one final hold-out independent. Distinguish parameter tuning from final evaluation.

Delivery contract

Produce the named files, record original and modified results, and export them through the corresponding Laboratory submission panel. The named ZIP is prepared locally; teacher collection is a separate step.
